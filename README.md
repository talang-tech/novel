# 《向上兼容》

> 一部关于沉默者的长篇职场小说

---

## 关于书名

**《向上兼容》** —— upward compatibility

- **技术义**：老系统要兼容新接口，旧代码要适配新规范。主角的整个技术生涯都在做兼容。
- **职场义**：向上管理 + 兼容领导 —— 一个人为了活下去，把自己改造成能被上级接口调用的形状。
- **痛处**：**兼容永远是下位者的义务。没人要求新系统向下兼容旧的人。**

## 一句话故事

一个不会说话的后端研发，在唯一护着他的老组长被调走后，被迫学习"如何让人看见自己"——**而当他终于学会时，他必须决定要不要变成那种人。**

## 核心命题

> **在一个不奖励沉默的系统里，一个沉默的人要怎么活下去？**

- 沉默不是美德，也不是缺陷。它是一种**没有被翻译的语言**。
- 逆袭不是"打败对手"，而是找到一种能让自己活下去、又不必背叛自己的表达方式。
- 每一次向上管理都有代价：说出来的话越漂亮，做事的手就越容易变脏。

## 写作规约

| 项 | 标准 |
|---|---|
| 单章字数 | 5000–6500 字 |
| 视角 | 第三人称限知，全程贴住主角。不写他不知道的事 |
| 对话密度 | 每章 25–40 段 |
| 技术细节 | 高浓度。SQL、日志、commit message、监控读数必须真实可信 |
| 文风 | 白描优先。少形容词，不解释人物心理 |

### 失控配额制 ⚠️

全书情绪失控 **总计不超过 5 次**。

| 卷 | 配额 |
|---|---|
| 卷壹 | 1 次（压到第 11–12 章） |
| 卷贰 | 1 次 |
| 卷叁 | 2 次（全书最高点） |
| 卷肆 | 0–1 次（越平静越好） |

主要情绪手法是**"想做但没做"** —— 写"差一点"，比写"真的"更有力。

### 禁忌

- ✗ "三年后我王者归来"式爽点
- ✗ 主角一夜开窍
- ✗ 反派降智（蒋辉、纪衡的判断经常是对的）
- ✗ 用旁白解释道理
- ✗ 主角骂人骂得很爽（他骂不出来，这是他的核心特征）
