# 《向上兼容》— 设定圣经

> 暂定书名：**《向上兼容》**
>
> **技术义：** backward/upward compatibility —— 老系统要兼容新接口，旧代码要适配新规范。陈稳的全部技术生涯都在做兼容。
> **职场义：** 向上管理 + 兼容领导 —— 一个人为了活下去，要把自己改造成能被上级接口调用的形状。
> **痛处：** 兼容永远是下位者的义务。没人要求新系统向下兼容旧的人。

| 书名 | 技术义 | 人事义 |

## 一、一句话故事

一个不会说话的后端研发，在唯一护着他的老组长被调走之后，被迫学习"如何让人看见自己"——而当他终于学会时，他必须决定要不要变成那种人。

## 二、核心命题

> **在一个不奖励沉默的系统里，一个沉默的人要怎么活下去？**

- 沉默不是美德，也不是缺陷。它是一种**没有被翻译的语言**。
- 逆袭不是"打败对手"，而是"找到一种能让自己活下去、又不必背叛自己的表达方式"。
- 每一次向上管理都有代价：说出来的话越漂亮，做事的手就越容易变脏。

## 三、基调与手法

| 维度 | 设定 |
|---|---|
| 节奏 | 慢热。前 15 章几乎没有"爽点"，靠细节和窒息感推进 |
| 视角 | 第三人称限知，全程贴住主角。读者只知道他知道的 |
| 文风 | 冷静、克制、白描。少形容词，多动作和物件。对话短，留白多 |
| 禁忌 | 不写"三年后我王者归来"；不让主角一夜开窍；不给反派降智 |
| 质感来源 | 真实的技术细节（告警、值班、回滚、代码评审）、真实的组织细节（OKR、汇报、双月复盘） |

## 四、公司设定

**恒澜科技**（业内简称"恒澜"）
- 老牌互联网大厂，鼎盛期已过，处在"降本增效"周期
- 主角所在：**商业中台 - 交易结算组**（俗称"结算组"）
- 结算系统是全公司最脏最累的地基：所有业务线的钱都从这里过
- 特点：**做好了没人知道，出事了全公司都知道**——这正是主角处境的隐喻

## 五、人物

### 陈稳 · 主角

| 项 | 内容 |
|---|---|
| 年龄 | 27 |
| 职级 | P6 后端研发，工龄 3 年，入职恒澜 1 年 |
| 出身 | 皖北小城，父亲是中学后勤，母亲在服装厂做工。家里砸锅卖铁供他读完 985 |
| 经济 | 房贷月供 9800，商贷 30 年。首付里有父母全部积蓄和舅舅借的 12 万 |
| 能力 | 真正的技术强手。对结算链路的理解全组第一，很多历史代码只有他敢改 |
| 缺陷 | 不会表达。开会时脑子里有答案，但话到嘴边就变成"嗯……这个可能有点复杂" |
| 习惯 | 用做事回应一切质疑。别人质疑他，他不辩解，回去把代码写得更好 |
| 口头禅 | "我看一下。"（他的万能回答，也是他的逃避方式） |
| 身体细节 | 工位常年放胃药。压力大时会无意识地反复刷新监控大盘 |

**他的错误信念（全书要打碎的东西）：**
> "只要我做得足够好，总会有人看见。"

**他的弧光：**
沉默的实干者 → 被逼学会翻译 → 学会了但开始厌恶自己 → 找到第三条路：不是变成蒋辉，也不是继续做透明人，而是**用自己的方式让工作说话**。

**名字的用意：** "陈稳"——他把"稳定"当信仰，而这个时代最不奖励的就是稳定。梁栋（承重的梁）被抽走后，全部重量压在他身上；他要么继续"稳"到被优化，要么学会不稳。

### 梁栋（老梁）· 前组长 / 主角的镜子

| 项 | 内容 |
|---|---|
| 年龄 | 42 |
| 职级 | P8，结算组组长，在恒澜 11 年 |
| 特点 | 技术极强，一线提拔上来。护着团队，但只在"他能护的范围内" |
| 弱点 | 不会向上博弈。汇报只讲事实不讲故事，被上面认为"缺乏影响力" |
| 与主角的关系 | 唯一读得懂陈稳代码的人。给他打过两次 B+，说"你值 A，但我拿不到 A" |
| 命运 | 第 3 章被"转岗"到技术支持中心（明升暗降），第 8 章离职 |

**他是主角的未来预警：** 如果陈稳继续沉默地做事，二十年后他就是老梁——技术很好、被人尊敬、然后被优化掉。

**关键台词：**
> "我一直以为把系统做稳了就是最大的政治。后来才知道，稳定这东西，没出事的时候等于零。"

### 纪衡 · 空降技术总监 / 主要对抗力量

| 项 | 内容 |
|---|---|
| 年龄 | 33 |
| 背景 | 顶级咨询公司 3 年 → 头部大厂技术管理 4 年 → 空降恒澜 |
| 能力 | **不是废物，这很重要。** 他真的有本事：叙事能力、资源整合、组织手腕都强 |
| 方法论 | 一切要"可度量、可讲述、可归因"。他不看代码，他看图 |
| 名言 | "我不需要你告诉我它多难，我需要你告诉我它值多少。" |
| 对主角 | 起初完全看不见他。后来发现他有用，开始"用"他 |

**他为什么不是简单的坏人：**
- 他推的很多改革其实是对的（服务治理、监控标准化）
- 他解决了老梁解决不了的资源问题
- 他的问题在于：**他只承认能被讲述的价值**

**他的悖论：** 他给了陈稳老梁永远给不了的机会，代价是要陈稳变成半个他。

## 六、意象系统（贯穿全书的物件）

| 意象 | 含义 |
|---|---|
| **监控大盘** | 主角的世界观：一切都该有指标。但他自己的价值没有指标 |

## 七、时间与结构

- 时间跨度：约 22 个月（两个完整绩效周期 + 一次组织架构调整 + 一次裁员）
- 篇幅：4 卷 62 章，每章 3000–4000 字，总计约 22 万字
- 每卷一个绩效/组织节点作为节拍器
