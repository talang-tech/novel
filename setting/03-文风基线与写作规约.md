# 文风基线 · 写作规约

> 每写新章前必读。第 1 章为文风基准样章。

---

## 一、基本参数

| 项 | 标准 |
|---|---|
| 单章字数 | 5000–6500 字（不含空白） |
| 视角 | 第三人称限知，全程贴住陈稳。**不写他不知道的事** |
| 对话密度 | 每章 25–40 段对话，分布在 2–3 个场景 |
| 技术细节 | 保持高浓度。SQL、日志、commit message、监控读数必须真实可信 |
| 时间锚点 | 大量使用精确时间（02:47 / 03:41 / 08:20）和精确数字（11,438 / 5,336 / 四百八） |

## 二、文风铁律

1. **白描优先。** 少形容词，少比喻。用动作、物件、数字代替情绪描写。
2. **不解释人物心理。** 让读者从行为里自己推断。
   - ✗ "他感到很委屈"
   - ✓ "他把这条删了，重新打：三千字没人看。"
3. **对话短。** 单句一般不超过 25 字。人物说话会跑题、会答非所问、会沉默。
4. **段落短。** 关键时刻单句成段。
5. **章末落点必须是画面或动作，不是总结。**

## 三、情绪失控的配额制 ⚠️

**这是全书最重要的节流阀。失控越少，每一次越值钱。**

### 配额

| 卷 | 允许的"真失控"次数 | 说明 |
|---|---|---|
| 卷壹（1–12） | **1 次** | 放在第 11–12 章（汇报被否 / 背 C），不能更早 |
| 卷贰（13–29） | **1 次** | 放在关键挫败处 |
| 卷叁（30–48） | **2 次** | 晋升失败 + 分手，全书情绪最高点 |
| 卷肆（49–62） | **0–1 次** | 越平静越好。他已经不需要靠情绪活着了 |

**全书总计不超过 5 次。**

### 什么算"真失控"

必须满足全部三条，否则只是"情绪波动"，不占配额：

1. 有**外显的失控行为**（摔、踹、吼、哭、当众顶撞、突然离场）
2. 有**在场的第二个人**看见，或造成实际后果
3. 事后有**代价**（关系恶化、被记录、身体反应、物品损坏）

### 允许的"未失控"写法（不限次数，鼓励使用）

这类才是本书的主要情绪手法 —— **写"差一点"，比写"真的"更有力**：

- 生理反应先于意识：手抖、胃疼、耳鸣、突然听不见声音
- **想做但没做**：想踹栏杆但没踹（第 1 章用法）
- 说了一句硬话，然后立刻自己收回
- 反复刷新监控大盘 / 反复删改一段文字
- 躲进楼梯间、洗手间、消防通道站几分钟
- 把愤怒转化成待办事项（他的核心防御机制）

**第 1 章示例（标准写法）：**

> 他忽然很想踹一脚那个栏杆。
>
> 他没有踹。
>
> 不是因为他想通了什么，是因为他知道，如果他踹了，声音会在楼梯井里往上滚三四层，会有人开门出来看。然后他就得解释。
>
> 而他不会解释。他从来不会。

## 四、人物说话规则

| 人物 | 说话特征 |
|---|---|
| **陈稳** | 极短。"嗯。""我看一下。""还行。"陈述句，不用感叹号。急了会突然变长且语速快，然后自己掐断 |
| **梁栋（老梁）** | 讲事实，不讲感受。偶尔一句穿透性的话（"别学我。"），说完就走 |
| **纪衡** | 全是问句，且都是量化问句。"影响多少钱？""延迟多久。"不寒暄，不解释 |
| **蒋辉** | 热情、轻快、真诚。**他的建议往往是对的**，这才是最难受的地方。不撒谎，只选择性呈现 |
| **易文** | 直接，不留情面，一句话戳到本质。会用反问 |
| **顾源** | 一次不超过三句。技术判断精准，人事上一律不表态 |
| **何晚** | 从生活侧发问，问题都很朴素但要命。"值班就是替别人擦屁股？" |

## 五、意象使用节奏

| 意象 | 用法 | 禁忌 |
|---|---|---|
| 监控大盘 | 每章可出现，作为陈稳的情绪外化 | 不点破它的象征意义 |
| 值班手机 | 出现即压力。"从来不关机" | 卷肆要交出去 |
| 胃药 | 只写数量变化（"还剩十一粒"），不写他难受 | 不描写胃疼的感觉 |
| 天花板裂缝 | 物业说"不影响结构" | 每卷最多用 1 次 |
| git commit | 他真正的表达出口。commit message 写得像散文 | — |
| 老梁的搪瓷杯 | 杯口有块磕掉的瓷 | 第 62 章前不能被收走 |
| 皮鞋（四百八，何晚买的） | 用来给代价标价 | — |

## 六、每章自检清单

写完必须逐条确认：

- [ ] 字数 5000–6500
- [ ] 对话段数 25–40
- [ ] 有至少一处真实技术细节（可执行、可验证）
- [ ] **没有超出本卷的失控配额**
- [ ] 没有解释人物心理活动
- [ ] 章末是画面/动作，不是总结
- [ ] 全书人名一致（陈稳/梁栋/纪衡/蒋辉/易文/顾源/何晚/万钧/陈根生/恒澜）
- [ ] 没有提前用掉后面章节的关键事件
- [ ] 至少埋 1 个后文可回收的细节

## 七、禁忌清单

- ✗ "三年后我王者归来"式的爽点
- ✗ 主角一夜开窍
- ✗ 反派降智（蒋辉、纪衡的判断经常是对的）
- ✗ 用旁白解释道理
- ✗ 金句堆砌（一章最多 1–2 句可引用的话）
- ✗ 提前透露后文事件
- ✗ 主角骂人骂得很爽（他骂不出来，这是他的核心特征）
