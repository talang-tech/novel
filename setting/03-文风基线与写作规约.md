# 文风基线 · 写作规约

> 每写新章前必读。第 1 章为文风基准样章。

---

## 一、基本参数

| 项 | 标准 |
|---|---|
| 单章字数 | 5000–6500 字（不含空白），**允许 ±200 字浮动**（即 4800–6700 均可接受） |
| 视角 | 第三人称限知，全程贴住陈稳。**不写他不知道的事** |
| 对话密度 | 每章 40–130 段对话，分布在 2–3 个场景（本书对话极短、一句一段，段数天然偏高；原「25–40」与实际写法不符，已按 23 章实测校准） |
| 技术细节 | 保持高浓度。SQL、日志、commit message、监控读数必须真实可信 |
| 时间锚点 | 大量使用精确时间（02:47 / 03:41 / 08:20）和精确数字（11,438 / 5,336 / 四百八） |

## 二、文风铁律

1. **白描优先。** 少形容词，少比喻。用动作、物件、数字代替情绪描写。
2. **不解释人物心理。** 让读者从行为里自己推断。
   - ✗ "他感到很委屈"
   - ✓ "他把这条删了，重新打：三千字没人看。"
3. **对话短。** 单句一般不超过 25 字。人物说话会跑题、会答非所问、会沉默。
4. **段落短。** 关键时刻单句成段。
5. **章末落点必须是画面或动作，不是总结。**

## 三、情绪失控的配额制 ⚠️

**这是全书最重要的节流阀。失控越少，每一次越值钱。**

### 配额

| 卷 | 允许的"真失控"次数 | 说明 |
|---|---|---|
| 卷壹（1–12） | **1 次** | 放在第 11–12 章（汇报被否 / 背 C），不能更早 |
| 卷贰（13–29） | **1 次** | 放在关键挫败处 |
| 卷叁（30–48） | **2 次** | 晋升失败 + 分手，全书情绪最高点 |
| 卷肆（49–62） | **0–1 次** | 越平静越好。他已经不需要靠情绪活着了 |

**全书总计不超过 5 次。**

### 什么算"真失控"

必须满足全部三条，否则只是"情绪波动"，不占配额：

1. 有**外显的失控行为**（摔、踹、吼、哭、当众顶撞、突然离场）
2. 有**在场的第二个人**看见，或造成实际后果
3. 事后有**代价**（关系恶化、被记录、身体反应、物品损坏）

### 允许的"未失控"写法（不限次数，鼓励使用）

这类才是本书的主要情绪手法 —— **写"差一点"，比写"真的"更有力**：

- 生理反应先于意识：手抖、胃疼、耳鸣、突然听不见声音
- **想做但没做**：想踹栏杆但没踹（第 1 章用法）
- 说了一句硬话，然后立刻自己收回
- 反复刷新监控大盘 / 反复删改一段文字
- 躲进楼梯间、洗手间、消防通道站几分钟
- 把愤怒转化成待办事项（他的核心防御机制）

**第 1 章示例（标准写法）：**

> 他忽然很想踹一脚那个栏杆。
>
> 他没有踹。
>
> 不是因为他想通了什么，是因为他知道，如果他踹了，声音会在楼梯井里往上滚三四层，会有人开门出来看。然后他就得解释。
>
> 而他不会解释。他从来不会。

## 四、人物说话规则

| 人物 | 说话特征 |
|---|---|
| **陈稳** | 极短。"嗯。""我看一下。""还行。"陈述句，不用感叹号。急了会突然变长且语速快，然后自己掐断 |
| **梁栋（老梁）** | 讲事实，不讲感受。偶尔一句穿透性的话（"别学我。"），说完就走 |
| **纪衡** | 全是问句，且都是量化问句。"影响多少钱？""延迟多久。"不寒暄，不解释 |
| **蒋辉** | 热情、轻快、真诚。**他的建议往往是对的**，这才是最难受的地方。不撒谎，只选择性呈现 |
| **易文** | 直接，不留情面，一句话戳到本质。会用反问 |
| **顾源** | 一次不超过三句。技术判断精准，人事上一律不表态 |
| **何晚** | 从生活侧发问，问题都很朴素但要命。"值班就是替别人擦屁股？" |

## 五、意象使用节奏

| 意象 | 用法 | 禁忌 |
|---|---|---|
| 监控大盘 | 每章可出现，作为陈稳的情绪外化 | 不点破它的象征意义 |
| 值班手机 | 出现即压力。"从来不关机" | 卷肆要交出去 |
| 胃药 | 只写数量变化（"还剩十一粒"），不写他难受 | 不描写胃疼的感觉 |
| 天花板裂缝 | 物业说"不影响结构" | 每卷最多用 1 次 |
| git commit | 他真正的表达出口。commit message 写得像散文 | — |
| 老梁的搪瓷杯 | 杯口有块磕掉的瓷 | 第 62 章前不能被收走 |
| 皮鞋（四百八，何晚买的） | 用来给代价标价 | — |

## 六、动作空转禁令 ⚠️ 新增

**这是当前最需要修正的问题。** 第 13–23 章体检数据：

| 句式 | 全书出现 | 问题 |
|---|---|---|
| 「没有说话」 | 205 次 | 第 23 章一章 41 次，平均每 155 字一次 |
| 「走到」 | 231 次 | |
| 「站起来」 | 217 次 | |
| 「坐下」 | 188 次 | |
| 「看了一眼」 | 126 次 | |

白描的本意是**克制**，不是**空转**。反面例句（第 23 章原文）：

> 他关掉电脑，站起来，走到纪衡的办公室门口，门开着，纪衡坐在办公桌前，看着电脑屏幕。
> 陈稳站在门口，没有说话。
> 纪衡抬起头，看着他。

四句话零信息。读者不需要知道他怎么走过去的。

### 硬性配额（每章）

| 句式 | 上限 |
|---|---|
| 「没有说话」及其变体（没有回答／没有接话／没说什么） | **≤ 3 次** |
| 「站起来」「坐下」「走到」「走出」合计 | **≤ 8 次** |
| 「看了一眼」「看着」合计 | **≤ 6 次** |
| 「点了点头」「嗯。」合计 | **≤ 5 次** |

### 三条替换规则

**1. 沉默必须带信息。** 沉默时人在干什么、看什么、身体有什么反应。

- ✗ 陈稳没有说话。
- ✓ 陈稳把杯子往左边推了两厘米，推到刚才的位置。

**2. 位移一律省略，直接切场景。** 除非路上发生了事。

- ✗ 他关掉电脑，站起来，走到纪衡的办公室门口。
- ✓ 纪衡的办公室门开着。

**3. 「看」要看出具体东西。** 看不出东西就删掉。

- ✗ 他看了一眼监控大盘。
- ✓ 结算成功率百分之九十九点九九，比昨天高了两个万分点。

## 七、场景张力清单 ⚠️ 新增

**每个场景开始前，先答这三个问题。答不出就不要写这个场景。**

1. **这个场景里，谁想从谁那里得到什么？**（没有索取就没有张力）
2. **谁在说谎、隐瞒或选择性呈现？**（全都实话实说的场景是死的）
3. **场景结束时，什么变了？**（信息、关系、处境——至少一样）

### 每章结构最低要求

- **开场 300 字内必须出现一个具体的麻烦**（告警、邮件、一句话、一个数字），不能从起床/通勤/看大盘开始
- **每章至少一次信息不对称**：陈稳知道而对方不知道，或反之
- **每章至少一个未解决的悬置**：一个没答的问题、一条没发的消息、一个不知道谁做的操作
- **章末落在动作或画面上**，且这个画面要**指向下一章**

### 反面模式（禁用）

- ✗ 从「早上起床/到工位/看监控大盘」开场（第 9、17、20、23 章都这样开的）
- ✗ 一整场只有信息交换、没有人有所图的会议
- ✗ 事情顺利解决、无人反对、无遗留问题
- ✗ 章末总结式收尾（「他知道，这件事还没有结束」）

## 八、连贯性钩子 ⚠️ 新增

**每章必须做到这三件事，让读者产生「下一章会怎样」的期待。**

1. **回收上一章埋的一个细节**（不必是大伏笔，一句话、一个数字都可以）
2. **推进一条长线**（10.14.1.88 是谁 / 索引谁删的 / 蒋辉欠的人情 / 何晚的观察）
3. **新埋一个具体的钩子**（不是抽象预感，是可验证的物件、数字、人名）

### 当前必须持续加压的四条长线

| 长线 | 当前状态 | 加压方式 |
|---|---|---|
| **10.14.1.88 是谁** | 09、10、17 章三次出现，仍未查明 | 每 3–4 章必须动一次，不能凉 |
| **索引被谁删的** | root@localhost，无 Git 记录 | 与 10.14.1.88 并线 |
| **蒋辉欠陈稳的人情** | 22 章 P0 陈稳没说根因 | 卷贰内必须兑现或反噬 |
| **何晚的层层观察** | 「你变了，但你不知道你变了」 | 每 2–3 章一次，为卷叁分手蓄力 |

- [ ] **开场 300 字内出现具体麻烦，不从起床/通勤/看大盘开场**（新增）
- [ ] **本章至少一次信息不对称**（新增）
- [ ] **本章至少一个未解决的悬置**（新增）
- [ ] **回收上章一个细节 + 推进一条长线 + 新埋一个钩子**（新增）

- [ ] 没有超出本卷的失控配额

- [ ] 章末是画面/动作，且指向下一章

- [ ] 没有提前用掉后面章节的关键事件

## 十、禁忌清单

- ✗ "三年后我王者归来"式的爽点
- ✗ 主角一夜开窍
- ✗ 反派降智（蒋辉、纪衡的判断经常是对的）
- ✗ 用旁白解释道理
- ✗ 金句堆砌（一章最多 1–2 句可引用的话）
- ✗ 提前透露后文事件
- ✗ 主角骂人骂得很爽（他骂不出来，这是他的核心特征）
