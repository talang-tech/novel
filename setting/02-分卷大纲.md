# 《向上兼容》— 分卷大纲

> 4 卷 62 章，每章 3000–4000 字，总计约 22 万字

---

## 卷壹 · 老办法（1–12 章 ≈ 4 万字）

**核心：** 陈稳用他唯一会的方式应对一切——埋头做事。但老办法全部失效。

**节拍器：** 第 1 次 OKR 对齐 + 双月汇报

### 分章概述

| 章 | 标题 | 内容 |
|---|---|---|
| 1 | **结算组** | 开场。凌晨 3 点，陈稳被值班手机叫醒。线上事故排查。他独自定位问题，修复，回滚。全程没有第二个人。结束后他写了一封很长的复盘邮件。 |
| 2 | **有人在看** | 复盘邮件只有纪衡回复了两个字："收到。" 陈稳不知道这意味着什么。老梁私下跟他说："纪总看了你的复盘，觉得写得太技术了，看不懂。" |
| 3 | **转岗** | 组织架构调整通知：梁栋调任技术支持中心，结算组暂时由纪衡直管。陈稳在小组群里看到消息，没有回复。他刷新了三次监控大盘。 |
| 4 | **送别** | 老梁约结算组吃散伙饭。陈稳坐在角落，没喝多少，但一直没说话。散场时老梁拍他肩膀："别学我。" |
| 5 | **新规矩** | 纪衡第一条要求：所有中台项目必须做"价值量化"。陈稳对着自己的任务清单，不知道怎么写。他花了三天写了一版，纪衡退回来："这是功能清单，不是价值。请重新想。" |
| 6 | **PPT 母版** | 纪衡发了新模板，要求月度汇报用这套格式。陈稳打开 PPT 母版，面对六个空白的占位符，坐了六个小时。他写不出来，因为他不知道怎么把"系统稳定运行"讲成一个故事。 |
| 7 | **蒋辉的方案** | 蒋辉在双月会上演示了一个"智能重试补偿方案"——本质上是陈稳在上个版本里做的一个优化模块。但蒋辉包装成了"跨部门协同优化"的战略项目。纪衡当场表扬。 |
| 8 | **老梁走了** | 老梁提了离职。陈稳在走廊上碰到他抱着纸箱等电梯。老梁说："我老婆说，再不走命都没了。" 电梯门关上。 |
| 9 | **值班** | 连续一周的值班排班落在陈稳头上。结算组做了重组，三个新人转岗进来，纪衡让他带。但新人问他问题，他讲不清楚，于是新人直接去问蒋辉。 |
| 10 | **胃** | 一整个月。陈稳吃了三盒胃药。何晚跟他吵架："你那公司是不是有毒？" 他说："还行。" |
| 11 | **第一次汇报** | 双月汇报。陈稳准备了四天，把 PPT 改了五版。上台讲了 8 分钟。纪衡没有打断，结束后只说了四个字："没有重点。" 散会后陈稳在洗手间里待了十五分钟。 |
| 12 | **背 C** | 绩效结果：C。半年内第一次。这意味着今年没有奖金，没有晋升，再有一次就进 PIP。陈稳把通知页面关掉，继续改代码。 |

**卷壹结尾状态：** 陈稳沉默地接受了所有结果。读者开始替他着急，**但他自己还没开始改变**。

## 卷贰 · 翻译（13–29 章 ≈ 6 万字）

**核心：** 陈稳被迫学习"翻译"——把技术价值翻译成组织语言。

**节拍器：** 第 2 次 OKR + 大促备战 + 架构评审

### 分章概述

| 章 | 内容 | 亮点 |
|---|---|---|
| 13 | 易文第一次出现。跨部门项目会议，陈稳又被蒋辉压了一头。会后易文追到走廊，问了他一个直击要害的问题。 | 易文的金句登场 |
| 14 | 陈稳被易文拉去参加一个"数据治理"的烂摊子项目。所有人都说不该接，但易文已经谈好了资源。 | 第一次见识"真正的谈判" |
| 15 | 陈稳发现易文的方法：她能让每个技术细节都对应一个业务指标。他问："你们分析师都是这样工作的吗？" 易文："不，我是这样工作的。" | 师徒关系的开端 |
| 16 | 大促备战开始。纪衡要求全部技术方案做"成本与收益预估"。陈稳第一次认真写这种东西。易文帮他改了三版。 | 第一次"翻译"成功 |
| 17 | 值班。凌晨 3 点，大促压测，一个历史负债问题暴露。陈稳独自修复，顺便把整个模块重构了。这次他写了两种复盘：技术版和汇报版。 | 技术实力的全景展示 |
| 18 | 纪衡第一次注意到他。不是因为技术，而是因为易文在汇报里引用了他的方案。纪衡问："这个人是谁？" | 标志性转折 |
| 19 | 陈稳被叫去参加一个技术决策会，见到了顾源。顾源在会议上只说了三句话，但每一句都被人听进去了。陈稳第一次意识到：**不说话的人也可以有分量。** | 第三条路的种子 |
| 20 | 何晚来公司附近等他下班。看到了凌乱的工位和胃药。她什么也没说。晚上她问："你是不是……不想干了？" 陈稳说："不是。" 他不确定自己说的是不是真的。 | 情感线的压力 |
| 21 | 蒋辉开始注意陈稳的变化。在茶水间里，蒋辉笑着说："你最近跟易文走得很近啊。" 陈稳听出了话里的意思。 | 微妙的竞争升级 |
| 22 | 结算系统发生 P0 事故。不是陈稳的锅，但他在现场。他做了一件事：在所有人都在追责的时候，他默默做了故障预案。这件事被纪衡看到了。 | 默默做事 vs 被看见开始统一 |
| 23 | 纪衡找他谈话，给了他一件事：一个"没人愿意做但有战略价值"的项目——结算系统对账模块重构。这是考验，也是机会。 | 第二次机会 |
| 24 | 陈稳接了这个项目。他做了详细的计划，写了技术方案，更重要的是——**他给易文打了个电话，问怎么把它讲成一个有故事的项目。** | 主角主动求变 |
| 25 | 项目推进。陈稳第一次主动在周会上讲了 3 分钟。虽然磕巴，但蒋辉发现他居然在"讲"了。 | 微小的胜利 |
| 26 | 重构过程中遇到一个"不可能"的技术难题。陈稳把自己关在工位三天。顾源路过，看了一眼屏幕，说了一句："你试试把这个缓存去掉。" 就走了。问题解决了。 | 隐性导师的指点 |
| 27 | 对账模块第一个版本上线。结算错误率下降了 84%。陈稳写了汇报，第一次没有让易文改。 | 成长的标志 |
| 28 | 双月汇报。陈稳讲了 15 分钟，**没有卡顿，没有超时，没有废话。** 纪衡听完，问了一个尖锐的问题，陈稳答了。纪衡点了头。 | 卷贰高潮 |
| 29 | 绩效结果：B+。进步了，但不够。陈稳开始意识到：**"能说了"不等于"能赢"。** 易文说："你才刚开始。" | 卷贰收束 |

**卷贰结尾状态：** 陈稳学会了"翻译"。但他开始发现，翻译也有代价——他说的每一句话，都在变成别人评价他的依据。

## 卷叁 · 代价（30–48 章 ≈ 7 万字）

**核心：** 陈稳越学越会，越走越深。但每进一步，都要付出点什么。

**节拍器：** 架构调整 + 晋升答辩 + 新一轮裁员

### 分章概述

| 章 | 内容 | 亮点 |
|---|---|---|
| 30 | 纪衡把结算组和营销技术组合并。陈稳和蒋辉成了同组。蒋辉主动示好，但陈稳已经不信任他了。 | 格局变化 |
| 31 | 合并后第一件事：资源分配。陈稳的项目被砍了一半资源。蒋辉的项目得到了全力支持。 | 现实 |
| 32 | 陈稳开始用自己的方式争取资源：他做了数据可视化，把"结算错误率下降 84%"换算成了"全年减少 1200 万资损"。纪衡批了。 | 他学会了——但心里不舒服 |
| 33 | 顾源要退休了。陈稳去找他，顾源说："你来找我，说明你已经开始变了。" | 顾源的告别 |
| 34 | 何晚问：什么时候结婚？陈稳说：等这次晋升完。何晚没说话。 | 关系的裂痕 |
| 35 | 晋升答辩准备。陈稳写了 3 万字的材料。易文帮他排了 3 次模拟。 | 战线拉长 |
| 36 | 蒋辉也报晋升。他们的材料撞了：同一个项目，两种讲法。陈稳的版本更真实，蒋辉的版本更好看。 | 核心冲突 |
| 37 | 答辩当天。陈稳讲了 30 分钟。评委问了一个关于"技术影响力"的问题——他本来可以答好，但他犹豫了一下，讲了实话。 | 诚实 vs 圆滑的抉择 |
| 38 | 结果：蒋辉晋升了，陈稳没有。理由是"影响力不足"。陈稳在工位坐到凌晨。 | 卷叁最低点 |
| 39 | 结算系统又出事了。这次是蒋辉负责的模块出了问题。陈稳在值班手机里看到告警，他没有动。然后他站起来，去了机房。 | 道德选择 |
| 40 | 他救了蒋辉的模块。蒋辉事后请他吃饭，说："我知道你帮了我。" 陈稳说："我不是帮你，我是帮系统。" | 性格的坚持 |
| 41 | 纪衡来找他，说有一个去"新业务孵化组"的机会——核心团队，直接向 VP 汇报。但条件是：需要他"能把事情讲清楚"。 | 抉择时刻 |
| 42 | 陈稳问易文的意见。易文说："你问这个问题，说明你已经想去了。" | 外部视角 |
| 43 | 他去了新业务孵化组。做的是他完全不懂的东西。他重新变成了"新人"。 | 归零 |
| 44 | 在新组，他遇到了一个比纪衡更难搞的领导——万钧，技术出身但已经完全商业化。 | 新阶段的挑战 |
| 45 | 陈稳第一次用"翻译术"在跨部门会议上争取到了资源。他成功了，但他觉得恶心。 | 伦理困境 |
| 46 | 何晚提了分手。不是吵架，是平静地说的："你变了，但你不知道你变了。" | 关系的断裂 |
| 47 | 陈稳在出租屋里坐了一整夜，想了很多。他想起老梁的结局，想起蒋辉的晋升，想起易文说过的话。 | 自我反思的转折点 |
| 48 | 他做了一个决定。不是辞职，不是投降，而是——**他要找到一种不需要背叛自己的方式。** | 卷叁结尾 |

**卷叁结尾状态：** 陈稳付出了代价——失去了女友，失去了部分自我。但他终于看清了棋局。

## 卷肆 · 第三条路（49–62 章 ≈ 5 万字）

**核心：** 陈稳不再试图变成"另一种人"，而是找到一种"让工作自己说话"的方式。

**节拍器：** 年度技术峰会 + 新一轮 OKR + 年终

### 分章概述

| 章 | 内容 | 亮点 |
|---|---|---|
| 49 | 陈稳回到结算组——不是被调回去，是他要求回去的。纪衡不理解。他说："我还没做完。" | 自主选择的力量 |
| 50 | 他开始做一件所有人都不理解的事：重写结算系统的核心链路。不是为了绩效，是为了"让系统配得上做这件事的人"。 | 技术理想主义 |
| 51 | 他找到了顾源。顾源退休后做顾问，答应帮他做架构评审。 | 传承 |
| 52 | 蒋辉被挖走了。他的离开在组里留下了一个巨大的空洞——不是技术上的，是"政治上的"。陈稳发现，他离开后，团队反而更安静了。 | 对手的落幕 |
| 53 | 结算系统重写的中期评审。陈稳邀请了所有相关方，用他自己写的工具做了一次**自动化的价值展示**——不需要他讲，系统自己跑给你看。 | 第三条路的雏形 |
| 54 | 纪衡看完沉默了。然后说："这在公司里没人这样做过。" 陈稳说："我知道。" | 认可 |
| 55 | 易文来找他，说："你找到办法了。" 陈稳说："不是我想出来的，是系统告诉我的。" | 角色关系的升华 |
| 56 | 年度技术峰会。陈稳被邀请做分享。他讲了"结算系统重写的技术选型与架构演进"。很多人听不懂，但所有人都知道他做了件了不起的事。 | 全社会认可 |
| 57 | 万钧（新业务组）又来找他，抛出了更高的 offer。陈稳拒绝了。 | 价值观的确认 |
| 58 | 年终绩效评定。纪衡给了陈稳 S。陈稳看到结果时，没有特别高兴。他打开 IDE，继续写代码。 | 平静的胜利 |
| 59 | 易文调到了别的事业部。告别时她说："你以后不再需要我帮你翻译了。" 陈稳说："你教我的东西，我还没还你。" 易文笑了。 | 告别的温度 |
| 60 | 何晚发了一条消息，说她要结婚了。陈稳看了很久，回了一个"恭喜"。 | 过去了 |
| 61 | 陈稳收到一封邮件：老梁在新的公司做技术负责人，问他有没有兴趣聊一聊。陈稳没有回复，但保留了邮件。 | 未来的可能性 |
| 62 | **结尾章。** 普通的一天。陈稳照常上班，改代码，看监控，写周报。他不再需要值班手机了——新人帮他顶上了。他走到窗前，看了一会儿云。然后回到工位，键盘声响起。 | 干净的结尾 |

**卷肆结尾状态：** 陈稳没有变成蒋辉，没有变成纪衡，也没有变成老梁。他变成了**一个能用自己的方式被看见的人**。

## 关键结构特征

### 章节奏
- 每 3–4 章一个小高潮（技术事故、组织变动、关键对话）
- 每卷末端一个大事（背 C / 晋升失败 / 分手 / 年终 S）
- 偶数章偏 "内心/生活"；奇数章偏 "外部事件/冲突"

### 伏笔系统
| 设置章 | 伏笔 | 回收章 |
|---|---|---|
| 1 | 结账核心链路陈稳最熟 | 50–53 重写核心链路 |
| 3 | 老梁说"别学我" | 61 老梁的新邮件 |
| 8 | 老梁离职 | 61 老梁发来邀请 |
| 15 | 易文的翻译方法 | 59 易文说"你不需要翻译了" |
| 19 | 顾源的"三句话" | 51 顾源答应做架构评审 |
| 24 | 陈稳主动求变 | 48 他做出决定 |
| 33 | 顾源说"你已经开始变了" | 55 陈稳找到办法 |

### 隐喻系统落地
- 监控大盘：第 1 章引入 → 第 61 章不再需要
- 胃药：第 10 章集中出现 → 卷肆消失
- 值班手机：第 1 章 → 第 62 章交接给新人
- 老梁的工位：第 8 章空了 → 第 62 章坐了新人
