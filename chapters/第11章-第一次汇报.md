# 第十一章 · 第一次汇报

八月二十六日，星期三。陈稳打开记事本，翻到双月会通知那一行，看了一遍，关掉。

他打开 PPT，新建一个空白文档，标题写了三个字：双月汇报。然后删掉，改成：结算系统七月至八月改进报告。他看了一眼，觉得不对，又删掉，留了一个空白的标题框。

光标在标题框里闪，一闪一闪的，他盯着它看了大概三十秒，没有打字。

他关掉 PPT，打开监控大盘，绿的，平的，结算成功率百分之九十九点九九，拦截器累计拦截四千二百一十七次，零资损。他看了一眼，关掉。

他打开数据库，执行了易文上次给他的 SQL，查了一下拦截器过去七天的数据。

```
  day    | total_requests | passed | blocked | alarmed
---------+----------------+--------+---------+---------
 08-22   |            627 |    627 |       0 |       0
 08-23   |            403 |    403 |       0 |       0
 08-24   |            211 |    211 |       0 |       0
 08-25   |            589 |    589 |       0 |       0
 08-26   |            401 |    401 |       0 |       0
```

他看了一眼，把数据复制到记事本里，然后关掉客户端。

他打开 PPT，把标题改成：**结算系统七月至八月改进报告——settle.guard 拦截器全量及规则引擎调度接入**。他在标题下面建了一个空白幻灯片，写了一个标题：全量数据。然后加了一个表格，把刚才查到的数据填进去，七行，每天的数据都在。他看了一眼，表格占了三行，看起来有点空。他加了一行副标题：**拦截器累计拦截 4,217 次，通过率 100%，0 资损。** 截至 2026-08-26 14:00。

他翻到第二页，写了一个标题：**规则引擎调度接入**。然后写了两行字：最多重试三次，间隔十五分钟。上线日期：2026-07-25。调度通知成功率 100%，未发生超时丢单。

他翻到第三页，写了一个标题：**业务价值**。他写了两行字：——拦截器全量运行后，凌晨事故从年均 2.3 次降至 0 次。——节省人力成本：48 人天/年。

他想了想，加了一行：——历史同类事故覆盖六次，预估累计减少资损约一万五千元。

他写完了，觉得数字不对，重新算了一下，最后写了一个数字：一万五千八百四十元。他想了想，把数字改成：约一万五千元。

他翻到第四页，写了一个标题：**下阶段计划**。然后写了三行十六个字：维护计划执行、配置变更监控、跨天时间窗优化。

他翻到第五页，写了一个标题：**问题与风险**。他写了两行字：——营销结算适配器限流配置被手动回滚两次，已增加配置变更检测。——索引删除事件仍在调查中。

他写完后，看了一遍，删掉最后一行，重新写：——索引删除事件调查中。

他关掉 PPT，看了一眼时间，下午五点四十分。他收拾东西，走出公司，去地铁站。

星期四早上，他打开 PPT，看了一遍，觉得不对，删掉第三页，重新写。他写了一个新的标题：**业务价值**。然后写了两行字：拦截器全量运行后，凌晨事故归零，资损归零，商户投诉归零。他写完后看了一遍，又删掉，改成：——拦截器覆盖后，凌晨事故归零。——资损归零。——商户投诉归零。

他写完后，觉得不对，删掉第一行，改成：——拦截器全量运行后，凌晨事故从年均 2.3 次降至 0 次。

他想了想，又加了一行：——节省人力成本：48 人天/年（减少凌晨事故排查和人工补结）。

他写完了，保存。

他打开记事本，翻到易文教他的那句话——"纪衡想问的是，影响多少钱。"

他想了想，加了一行字：拦截器已覆盖历史六次同类事故，预估累计减少资损约一万五千元。

他关上记事本，打开 PPT，在第三页加了一行：——历史同类事故覆盖六次，预估累计减少资损约一万五千元。

下午两点，他给易文发了一条消息：PPT 写完了，能看一下吗。

易文没有回复。

他等了十分钟，又发了一条：不急。

易文还是没有回复。

他关掉微信，打开 PPT，从头到尾翻了一遍，觉得第三页数据太多，删掉两行，剩下的行看起来更空了。他把表格加粗，调整了一下字号，让页面看起来更满一些。

他打开监控大盘，绿的，平的，结算成功率百分之九十九点九九，拦截器正常，连接池使用率百分之六十九。他看了一眼，关掉。

下午四点，易文回复了。两个字：发来。

陈稳把 PPT 发过去，然后坐在工位上等。他打开数据库，执行了一遍拦截器数据查询，数据没有变化，跟昨天一样。他关掉客户端，打开记事本，看了一眼明天的汇报顺序：陈稳第一。

下午五点二十分，易文的电话打了过来。

"第一页可以。第二页可以。第三页，把那个数字改成一万五千八百四十，纪衡喜欢精确数字。"

"好。"

"第四页，把下阶段计划改成三行，每行四个字，不要写句子。"

"好。"

"第五页，你那个问题与风险，把索引删除那行删了，纪衡会在会上问，你现在答不上来。"

"好。"

"你今晚在办公室讲一遍，录下来，自己听一遍。"

"好。"

陈稳放下手机，打开 PPT，按照易文说的改了一遍。第三页的数字改成一万五千八百四十，第四页的三行改成十六个字——维护计划执行、配置变更监控、跨天时间窗优化。第五页的索引删除行删掉，改成：——营销结算适配器限流配置变更检测已上线。

他改完了，保存，然后站起来，走到三楼会议室。会议室没有人，他走进去，关上门，打开投影仪，把 PPT 投上去，然后站到讲台前面，看着屏幕，沉默了一会儿。

他开口说："大家好，我是结算组的陈稳。七月到八月，我们做了三项工作——拦截器全量、规则引擎调度接入、配置变更检测。"

他说完，觉得顺序不对，又说了一遍，这次把配置变更检测放到最后。

他讲了三遍，第四遍的时候，他开了手机录音，放在讲台上，然后完整地讲了一遍。他讲完，拿起手机，关掉录音，回到工位，戴上耳机，听了一遍。

他听到自己的声音，比平时低，比平时快，每句话的结尾会往下掉，像是没有力气把最后一个字说完。他听到自己说"一万五千八百四十"的时候，顿了一下，然后快速带过，像是不确定这个数字是不是对的。他听到自己说"谢谢"的时候，声音很小，像是说给自己听的。

他听完，放下手机，坐在工位上，没有动。

他打开 PPT，重新看了一遍，觉得每页上都少了一句话，但他不知道缺的是什么。他想了想，把第一页的标题改了一下，加了一个冒号，然后删掉，恢复原样。他关掉 PPT，站起来，走到茶水间，倒了一杯水，喝了一口，温的，胃没有反应。

他站在茶水间里，看着窗外的楼，对面那栋楼，窗户亮着，三楼，五楼，七楼，八楼，九楼。他看了十一个月的那扇窗，还是黑的。

他站了一会儿，走回工位，打开记事本，写了两行字：

"明天十点，三楼会议室，汇报顺序第一。"
"讲了可能不到十五分钟，但准备到十五分钟。"

他写完，关掉记事本，看了一眼时间，晚上七点四十分。他收拾东西，走出公司，去地铁站。

星期五早上，他七点起床，洗漱，换衣服，穿何晚买的那双皮鞋，四百八，鞋尖起皱。他走到地铁站，刷卡进站，等车，列车来了，他走进去，站了一路，抓着扶手，看着窗外黑色的隧道，偶尔有光照进来，是站台上的灯。

他八点四十分到公司，打开电脑，打开 PPT，从头到尾看了三遍，确认没有错别字，确认数字跟数据源一致，确认每页的格式跟纪衡的模板一致。他打开监控大盘，绿的，平的，结算成功率百分之九十九点九九，拦截器正常，连接池使用率百分之六十八。

他关掉监控，站起来，走到三楼会议室，推开门，里面没有人。空调开着，桌面上摆着七瓶水，每瓶前面放了一张打印好的名牌——陈稳、蒋辉、资深工程师、纪衡，还有三个空位，没有名字。他找到自己的名牌，在靠左的位置，离投影仪最远的地方。他坐下来，把水拧开，喝了一口，凉的，胃缩了一下，他把水放下，没有继续喝。

他坐在那里，等了一会儿。会议室的门被推开，蒋辉走了进来，手里拿着一台笔记本电脑，银色的，键盘上贴了几张便利贴，黄色的，字很小。

"早。"

"早。"

蒋辉坐下来，把电脑打开，接上电源，打开 PPT，翻了一遍，然后合上，看向陈稳。

"你今天第几个。"

"第一个。"

"我第二个。纪总说你第一个，挺好的，先讲完就可以放松了。"

"你准备了多久。"

"四天。"

"差不多。我准备了两天，但昨天改到凌晨两点。"

陈稳点了点头。

九点五十分，会议室的人陆续进来。资深工程师，坐在靠窗的位置，打开笔记本，没有看任何人。数据组的人，两个，陈稳不认识，坐到没有名字的空位上。然后纪衡走了进来，穿着深蓝色衬衫，袖子卷起来，手里拿着一个黑色笔记本，没有电脑。

纪衡坐下来，看了一眼会议室里的人，说："开始吧。"

陈稳站起来，走到投影仪前面，把 PPT 投上去，然后站在讲台前面，看着屏幕。他停了两秒，然后开口。

"大家好，我是结算组的陈稳。今天汇报的内容是结算系统七月至八月的改进情况。"

他按了一下遥控器，翻到第一页。

"第一页，全量数据。settle.guard 拦截器于七月二十八日全量上线，累计拦截四千二百一十七次请求，通过率百分之百，零资损。截至八月二十六日，全量运行三十天，未发生凌晨事故。"

他翻到第二页。

"第二页，规则引擎调度接入。调度通知于七月二十五日上线，支持最多重试三次，间隔十五分钟，上线后调度通知成功率百分之百，未发生超时丢单。"

他翻到第三页。

"第三页，业务价值。拦截器覆盖历史同类事故六次，预估累计减少资损一万五千八百四十元。同时，节省人力成本约四十八人天每年，主要来自凌晨事故排查和人工补结的减少。"

他翻到第四页。

"第四页，下阶段计划。三项工作：维护计划执行、配置变更监控上线、跨天时间窗逻辑优化。其中跨天时间窗逻辑优化已于七月二十九日完成，配置变更监控于八月第三周上线。"

他翻到第五页。

"第五页，问题与风险。营销结算适配器限流配置被手动回滚两次，已增加配置变更检测，在适配器启动时对比配置文件哈希值与 Git 提交哈希值，不一致时告警。目前该检测运行正常。"

他翻到最后一页，空白页，上面只写了一行字：谢谢。

他停了一下，说："汇报完毕。"

会议室没有声音。

陈稳站在讲台前面，看着下面的人。蒋辉在看电脑，没有抬头。资深工程师在看自己的笔记本，没有抬头。数据组的两个人，一个人在喝水，另一个在写东西。纪衡坐在最前面，靠着椅背，看着陈稳，没有表情。

过了大概三秒，纪衡开口了。

"你讲完了？"

"讲完了。"

"你用了七分钟。"

"嗯。"

"七分钟，你讲了五页。每页两句话，讲完就翻。你有没有想过，这些数据我应该怎么看。"

陈稳没有说话。

"你给了我一堆数字——四千二百一十七次，一万五千八百四十元，百分之百，四十八人天。这些数字是好的，但你告诉我，它们之间有什么关系。四千二百一十七次拦截，跟一万五千八百四十元，是怎么算出来的。你刚才说，拦截器覆盖了历史同类事故六次，每次影响商户约一千二百户，每次延迟三十三分钟。但你有没有算过，这六次事故里，有多少次是拦截器真的能拦住的。你刚才说百分之百，但你的数据只有三十天，三十天不够说话。"

陈稳站在讲台前面，看着纪衡，没有说话。

"你最后留了一个问题，限流配置被回滚，你做了检测。然后呢。你查了是谁回滚的吗。回滚的原因是什么。是配置错了，还是流程有问题。你没有说。"

纪衡停了一下，看着陈稳。

"你今天的汇报，准备了很多，但你没有把重点讲出来。你讲了很多事，但每件事都只讲了开头，没有讲结果。你讲了拦截器的数据，数据是好的，但你没有告诉我，这些数据意味着什么。你讲了规则引擎，只讲了两句话，我看不到这个东西跟拦截器之间的关系。你讲了价值量化，数字是对的，但你没有解释为什么是这些数字。"

纪衡靠回椅背，看着陈稳。

"没有重点。"

陈稳站在讲台前面，没有说话。他听到自己的心跳，跳得很快，比平时快，比他录音的时候快。他感觉到自己的手在抖，很轻，只有他自己知道，他握着遥控器，遥控器没有动，但他的手指在抖。

他张了张嘴，想说点什么，但没有说出来。

纪衡说："你先坐下吧。"

陈稳走回自己的位置，坐下来，把遥控器放在桌上，拿起水，喝了一口，凉的，胃缩了一下，他放下水，没有继续喝。

蒋辉站起来，走到讲台前面，打开 PPT，开始讲。陈稳坐在椅子上，看着蒋辉的背影，听不到他在说什么。他听到自己的心跳，很快，很响，像是在他耳朵里，一下一下的，盖过了蒋辉的声音。

他坐在那里，感觉椅子很硬，空调很冷，手上的汗把遥控器弄湿了，留下一层湿印子在桌面上。他看着桌面上那层湿印子，看着它慢慢变干，边缘变白，中间变浅，最后消失。

他抬起头，看到蒋辉 PPT 上的一行字：**智能重试补偿方案——跨部门协同优化，提升结算可靠性与用户体验**。

他听到蒋辉说："这个方案的核心是复用。结算系统已有的重试机制，加上营销侧的数据补偿逻辑，可以做一层统一的补偿层。我算了一下，大概百分之四十需要新建，百分之六十是现成的。"

纪衡说："现成的部分，你验证过没有。"

蒋辉说："验证过。陈稳的重试机制上线一个月了，调度通知成功率百分之百，没有出现丢单。数据可以直接复用。"

陈稳坐在椅子上，听到自己的名字，但没有抬头。他盯着桌面，看到那层湿印子已经完全干了，桌面上什么都没有，只有白色的光，从天花板上照下来，照在桌面上，反射出柔和的、灰色的、没有温度的光。

他听到蒋辉在讲，讲得很流畅，每一页转场的时候会说一句"下一张是"，结束的时候会说"简单来说"。他听到纪衡在问问题，蒋辉在回答，有时候纪衡不说话，蒋辉就继续说。

他听到纪衡说："这个方案，两周后带数据组一起评估。"

他听到蒋辉说："好。"

他听到会议室里其他人开始说话，椅子响了，水瓶被拧开，有人站起来，有人走出去。他听到蒋辉走回自己的位置，坐下来，把电脑合上。

他坐在椅子上，没有动。

他感觉到有人看了他一眼，然后移开，然后是别的声音，别的话，别的人，都在他周围，在他耳边，但跟他没有关系。

他坐在椅子上，坐了很久，久到会议室里只剩下他一个人。他站起来，走出会议室，走进走廊，走廊上没有人，他走到洗手间，推开门，走进去，关上门，站在洗手台前面，看着镜子里的自己。

镜子里的脸没有什么表情，跟平时一样，看不出什么。他盯着镜子里的自己，看了大概十秒，然后低下头，打开水龙头，冷水，冲了冲手，然后把水关了，站在那里，手上还滴着水，水珠滴在洗手台上，一滴，一滴，规律的，像是计时器。

他站在那里，没有动。

他听到自己的心跳，已经慢下来了，比刚才慢，比平时也慢。他听到墙上挂钟的声音，秒针在走，一下，两下，三下，跟水珠滴落的声音叠在一起，一个快，一个慢，像是在互相追赶。

他站了一会儿，然后抬起头，看着镜子里的自己。镜子上有一层水雾，是刚才冲水的时候溅上去的，把镜子里的人脸模糊了一半，像是被什么东西盖住了，看不清楚。

他抬手，用袖子擦了一下镜子，擦出一块干净的圆形，能看到自己的眼睛。他盯着那双眼睛看了一会儿，然后低下头，打开水龙头，又冲了冲手，然后关上，转身，推开门，走出洗手间。

走廊上没有人。他走回自己的工位，坐下来，打开电脑，打开监控大盘，绿的，平的，结算成功率百分之九十九点九九，拦截器正常，连接池使用率百分之六十九。他看了一眼，关掉，打开 IDE，打开配置变更检测的代码，读了一遍，十五行，逻辑正确，没有 bug。

他关掉 IDE，打开记事本，翻到今天写的那两行字。

"明天十点，三楼会议室，汇报顺序第一。"
"讲了可能不到十五分钟，但准备到十五分钟。"

他看了一遍，然后把这两行删掉，在下面写了两行新的：

"学了。"
"没学会。"

他写完，盯着这两行字，看了一会儿，然后删掉，关掉记事本，站起来，走到茶水间，倒了一杯水，喝了一口，凉的，胃缩了一下，他没有放下，继续喝，喝完了，把杯子放在水槽里，没有洗。

他走回工位，坐下来，看了一眼时间，十一点十二分。他打开手机，看到易文发了一条消息。

"纪衡说了什么。"

陈稳打了几个字，删掉，又打，又删掉，最后发了三个字。

"没有重点。"

易文没有回复。

他把手机放在桌上，屏幕朝上，等了一会儿，没有消息。他打开监控大盘，绿的，平的，结算成功率百分之九十九点九九，拦截器正常，连接池使用率百分之六十八。他看了一眼，关掉，然后打开记事本，在最后一行写了一个新的待办事项：

"问易文，今晚能不能打个电话。"
