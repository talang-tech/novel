# 第十一章 · 第一次汇报

八月二十六日，星期三，上午九点三十八分。纪衡的邮件标题只有一行：双月会 8/28 10:00 三楼会议室，每人十五分钟。

正文两行。第一行：汇报顺序，陈稳，蒋辉。第二行：把这两个月你做的事，讲清楚。

附件是座位表。七个位置，有名字的四个，剩下三个空着，排在纪衡右手边。陈稳不知道那三个是谁。

十五分钟。他上一次在超过五个人的会上开口，是去年十二月的部门年会，他说的是"谢谢"，两个字。

他打开 PPT，新建一个空白文档，标题写了三个字：双月汇报。删掉，改成：结算系统七月至八月改进报告。太长，又删掉，留了一个空的标题框。

光标在标题框里闪，一闪一闪的，闪了大概三十秒。

拦截器全量三十天，累计拦截四千二百一十七次，零资损。这三个数他每天都在看，没有一天想过要怎么讲给别人听。

他执行了易文上次给他的 SQL，查拦截器过去七天的数据。

```
  day    | total_requests | passed | blocked | alarmed
---------+----------------+--------+---------+---------
 08-22   |            627 |    627 |       0 |       0
 08-23   |            403 |    403 |       0 |       0
 08-24   |            211 |    211 |       0 |       0
 08-25   |            589 |    589 |       0 |       0
 08-26   |            401 |    401 |       0 |       0
```

五天里有三天不到五百笔，blocked 一直是零。他把数据复制到记事本里，关掉客户端。

他把标题改成：**结算系统七月至八月改进报告——settle.guard 拦截器全量及规则引擎调度接入**。第一页标题：全量数据。表格七行，每天一行。表格只占了三行的高度，页面下半截是空的。他加了一行副标题：**拦截器累计拦截 4,217 次，通过率 100%，0 资损。** 截至 2026-08-26 14:00。

他翻到第二页，写了一个标题：**规则引擎调度接入**。然后写了两行字：最多重试三次，间隔十五分钟。上线日期：2026-07-25。调度通知成功率 100%，未发生超时丢单。

他翻到第三页，写了一个标题：**业务价值**。他写了两行字：——拦截器全量运行后，凌晨事故从年均 2.3 次降至 0 次。——节省人力成本：48 人天/年。

他想了想，加了一行：——历史同类事故覆盖六次，预估累计减少资损约一万五千元。

他写完了，觉得数字不对，重新算了一下，最后写了一个数字：一万五千八百四十元。他想了想，把数字改成：约一万五千元。

他翻到第四页，写了一个标题：**下阶段计划**。然后写了三行十六个字：维护计划执行、配置变更监控、跨天时间窗优化。

他翻到第五页，写了一个标题：**问题与风险**。他写了两行字：——营销结算适配器限流配置被手动回滚两次，已增加配置变更检测。——索引删除事件仍在调查中。

他写完后删掉最后一行，重新写：——索引删除事件调查中。

索引是谁删的，他到现在只查到一条记录：root@localhost，没有 Git 提交记录，没有工单号。这行字他在 PPT 上留了三次，删了三次。

下午五点四十分。

星期四早上，第三页整页删掉，重新写。标题还是**业务价值**，内容改成三行：拦截器全量运行后，凌晨事故归零，资损归零，商户投诉归零。他又把三行拆成三个破折号：——拦截器覆盖后，凌晨事故归零。——资损归零。——商户投诉归零。

他写完后，觉得不对，删掉第一行，改成：——拦截器全量运行后，凌晨事故从年均 2.3 次降至 0 次。

他想了想，又加了一行：——节省人力成本：48 人天/年（减少凌晨事故排查和人工补结）。

他写完了，保存。

他打开记事本，翻到易文教他的那句话——"纪衡想问的是，影响多少钱。"

他想了想，加了一行字：拦截器已覆盖历史六次同类事故，预估累计减少资损约一万五千元。

他关上记事本，打开 PPT，在第三页加了一行：——历史同类事故覆盖六次，预估累计减少资损约一万五千元。

下午两点，他给易文发了一条消息：PPT 写完了，能看一下吗。

易文没有回复。

他等了十分钟，又发了一条：不急。

易文还是没有回复。

他从头到尾翻了一遍，第三页删掉两行，剩下的行看起来更空。他把表格加粗，字号从十八调到二十，页面看起来满了一点。

连接池使用率百分之六十九，比上周同一时段高了四个点。他记下来，没有写进 PPT。

下午四点，易文回复了。两个字：发来。

陈稳把 PPT 发过去。他又执行了一遍拦截器数据查询，跟两小时前一个字都没差。记事本上那行还在：汇报顺序，陈稳第一。

下午五点二十分，易文的电话打了过来。

"第一页可以。第二页可以。第三页，把那个数字改成一万五千八百四十，纪衡喜欢精确数字。"

"好。"

"第四页，把下阶段计划改成三行，每行四个字，不要写句子。"

"好。"

"第五页，你那个问题与风险，把索引删除那行删了，纪衡会在会上问，你现在答不上来。"

"好。"

"座位表你看了吗。"

"看了。三个空位。"

"数据组的。他们不管你的东西，他们管蒋辉的东西。"

"蒋辉的什么东西。"

易文停了两秒。

"你明天就知道了。"

"你今晚在办公室讲一遍，录下来，自己听一遍。"

"好。"

陈稳按易文说的改了一遍。第三页的数字改成一万五千八百四十，第四页的三行改成十六个字——维护计划执行、配置变更监控、跨天时间窗优化。第五页的索引删除行删掉，改成：——营销结算适配器限流配置变更检测已上线。

这一行删掉之后，这两个月他花掉的十四个小时——翻二十三天的 binlog、比对四个环境的建表语句、给 DBA 发过三封邮件——在 PPT 上就不存在了。

三楼会议室是空的。他把 PPT 投上去，投影仪的风扇声比想象的大。

他开口说："大家好，我是结算组的陈稳。七月到八月，我们做了三项工作——拦截器全量、规则引擎调度接入、配置变更检测。"

他说完，觉得顺序不对，又说了一遍，这次把配置变更检测放到最后。

他讲了三遍。第四遍开了手机录音，放在讲台边上，完整讲了一遍，七分十秒。

他听到自己的声音，比平时低，比平时快，每句话的结尾会往下掉，像是没有力气把最后一个字说完。他听到自己说"一万五千八百四十"的时候，顿了一下，然后快速带过，像是不确定这个数字是不是对的。他听到自己说"谢谢"的时候，声音很小，像是说给自己听的。

他把录音听到第三遍，删了。

每页上都少了一句话，他知道少了，不知道少的是什么。他给第一页的标题加了一个冒号，又删掉。

茶水间的水是温的，胃没有反应。对面那栋楼，三楼五楼七楼八楼九楼都亮着。他看了十一个月的那扇窗，还是黑的。

记事本上多了两行字：

"明天十点，三楼会议室，汇报顺序第一。"
"讲了可能不到十五分钟，但准备到十五分钟。"

晚上七点四十分。

星期五早上七点，他穿了何晚买的那双皮鞋，四百八，鞋尖起皱。地铁上他一直站着，抓着扶手，隧道是黑的，偶尔有光扫进来，是站台的灯。

八点四十分，他把 PPT 从头到尾过了三遍：没有错别字，数字跟数据源一致，页边距跟纪衡的模板一致。连接池使用率百分之六十八，比昨天低了一个点。

九点二十分，三楼会议室的空调已经开了。桌上七瓶水，每瓶前面一张打印的名牌——陈稳、蒋辉、资深工程师、纪衡，另外三张是空白的。他的名牌在最靠左，离投影仪最远。水是凉的，喝了一口，胃缩了一下，他把瓶子放下。

门被推开，蒋辉进来，手里一台银色笔记本，键盘上贴了四张黄色便利贴，字很小。

"早。"

"早。"

蒋辉坐下来，把电脑打开，接上电源，打开 PPT，翻了一遍，然后合上，看向陈稳。

"你今天第几个。"

"第一个。"

"我第二个。纪总说你第一个，挺好的，先讲完就可以放松了。"

"你准备了多久。"

"四天。"

"差不多。我准备了两天，但昨天改到凌晨两点。"

蒋辉的便利贴上，最上面那张写着两个字：数据组。

九点五十分，人陆续进来。那位资深工程师在靠窗的位置打开笔记本，一句话没说。两个陌生人坐到没有名字的空位上，其中一个把电脑摆在蒋辉旁边，两个人低声说了三四句话。纪衡最后进来，深蓝衬衫，袖子卷到小臂，手里一个黑色本子，没带电脑。

纪衡把本子摊开，说："开始吧。"

HDMI 线插进去的时候投影仪响了一声。他停了两秒，开口。

"大家好，我是结算组的陈稳。今天汇报的内容是结算系统七月至八月的改进情况。"

他按了一下遥控器，翻到第一页。

"第一页，全量数据。settle.guard 拦截器于七月二十八日全量上线，累计拦截四千二百一十七次请求，通过率百分之百，零资损。截至八月二十六日，全量运行三十天，未发生凌晨事故。"

他翻到第二页。

"第二页，规则引擎调度接入。调度通知于七月二十五日上线，支持最多重试三次，间隔十五分钟，上线后调度通知成功率百分之百，未发生超时丢单。"

他翻到第三页。

"第三页，业务价值。拦截器覆盖历史同类事故六次，预估累计减少资损一万五千八百四十元。同时，节省人力成本约四十八人天每年，主要来自凌晨事故排查和人工补结的减少。"

他翻到第四页。

"第四页，下阶段计划。三项工作：维护计划执行、配置变更监控上线、跨天时间窗逻辑优化。其中跨天时间窗逻辑优化已于七月二十九日完成，配置变更监控于八月第三周上线。"

他翻到第五页。

"第五页，问题与风险。营销结算适配器限流配置被手动回滚两次，已增加配置变更检测，在适配器启动时对比配置文件哈希值与 Git 提交哈希值，不一致时告警。目前该检测运行正常。"

他翻到最后一页，空白页，上面只写了一行字：谢谢。

他停了一下，说："汇报完毕。"

会议室里只有空调的声音。

蒋辉的手指停在触控板上没有抬头。资深工程师在自己的笔记本上写字。数据组那两个人，一个在拧水瓶，一个在打字。纪衡靠着椅背，本子摊在桌上，一个字都没记。

过了大概三秒，纪衡开口了。

"你讲完了？"

"讲完了。"

"你用了七分钟。"

"嗯。"

"七分钟，你讲了五页。每页两句话，讲完就翻。你有没有想过，这些数据我应该怎么看。"

这五页他改了四天，第三页改了七遍。他不知道该在哪一遍上停。

"你给了我一堆数字——四千二百一十七次，一万五千八百四十元，百分之百，四十八人天。这些数字是好的，但你告诉我，它们之间有什么关系。四千二百一十七次拦截，跟一万五千八百四十元，是怎么算出来的。你刚才说，拦截器覆盖了历史同类事故六次，每次影响商户约一千二百户，每次延迟三十三分钟。但你有没有算过，这六次事故里，有多少次是拦截器真的能拦住的。你刚才说百分之百，但你的数据只有三十天，三十天不够说话。"

六次里能拦住的是四次，另外两次是上游超时，拦截器管不着。这个数陈稳算过，写在记事本第二十六页，没有写进 PPT——因为写进去，四次比六次少两次。

"你最后留了一个问题，限流配置被回滚，你做了检测。然后呢。你查了是谁回滚的吗。回滚的原因是什么。是配置错了，还是流程有问题。你没有说。"

这一行昨天下午五点二十分还在 PPT 上。删它的人是易文，理由是"你现在答不上来"。陈稳确实答不上来。

"你今天的汇报，准备了很多，但你没有把重点讲出来。你讲了很多事，但每件事都只讲了开头，没有讲结果。你讲了拦截器的数据，数据是好的，但你没有告诉我，这些数据意味着什么。你讲了规则引擎，只讲了两句话，我看不到这个东西跟拦截器之间的关系。你讲了价值量化，数字是对的，但你没有解释为什么是这些数字。"

纪衡靠回椅背，把本子合上。

"没有重点。"

他的心跳比录音的时候快。他握着遥控器，遥控器没有动，他的手指在抖，很轻，只有他自己知道。

他有一句话在嘴里：四次能拦，两次不能，剩下的两次是上游超时。这句话说出来要六秒。

他没有说。

不是因为不敢。是因为他知道，说出来之后纪衡会问"那你为什么写六次"，而这个问题的答案是"因为六比四大"。他不会说这句话。他从来不会。

纪衡说："你先坐下吧。"

遥控器放回桌上的时候，桌面上多了一小块湿印子。他拿起水，凉的，胃缩了一下，放下。

蒋辉的 PPT 亮起来，第一行字是：**智能重试补偿方案——跨部门协同优化，提升结算可靠性与用户体验**。他听不见蒋辉在说什么，只听见自己的心跳，一下一下压在耳朵里。

桌面上那块湿印子在慢慢变干，边缘先变白，中间变浅，最后没有了。

他听到蒋辉说："这个方案的核心是复用。结算系统已有的重试机制，加上营销侧的数据补偿逻辑，可以做一层统一的补偿层。我算了一下，大概百分之四十需要新建，百分之六十是现成的。"

纪衡说："现成的部分，你验证过没有。"

蒋辉说："验证过。陈稳的重试机制上线一个月了，调度通知成功率百分之百，没有出现丢单。数据可以直接复用。"

调度通知成功率百分之百这个数，是陈稳七月二十五日上线那天开始记的，他一天记一次，记了三十四天。蒋辉从来没有找他要过这份数据。

蒋辉讲得很流畅。每一页转场说一句"下一张是"，收尾说一句"简单来说"。纪衡问了六个问题，蒋辉答了六个。有两次纪衡没接话，蒋辉就自己往下讲。

他听到纪衡说："这个方案，两周后带数据组一起评估。"

他听到蒋辉说："好。"

椅子响，水瓶被拧开，脚步声一层一层退出去。蒋辉合上电脑的时候说了一句"辛苦了"，说给整个屋子，不是给某一个人。

有人在门口回头看了他一下，两秒，移开。

会议室里最后只剩他一个。空调还在吹，投影仪的蓝屏还亮着，HDMI 线还插在他电脑上。他把线拔下来，绕了三圈。

洗手间的镜子上有一层水雾，是他冲手的时候溅上去的，把脸糊掉一半。冷水关掉之后，手上的水珠一滴一滴掉在洗手台上，规律的。墙上挂钟的秒针在走，比水珠快。

他的心跳已经慢下来了，比刚才慢，比平时也慢。

他抬手用袖子擦了一下镜子，擦出一块干净的圆，正好露出眼睛。

他在这里待了十五分钟。这十五分钟里没有人推门进来。

配置变更检测的代码十五行，逻辑正确，没有 bug。连接池使用率百分之六十九。这两件事今天上午都没有变过。

记事本上还是昨晚那两行：

"明天十点，三楼会议室，汇报顺序第一。"
"讲了可能不到十五分钟，但准备到十五分钟。"

他把这两行删掉，写了两行新的：

"学了。"
"没学会。"

光标在"没学会"后面闪了大概十秒。他把这两行也删了。

茶水间的水是凉的，胃缩了一下，他没停，一口气喝完，杯子放进水槽，没洗。

十一点十二分。手机上有一条易文的消息。

"纪衡说了什么。"

陈稳打了几个字，删掉，又打，又删掉，最后发了三个字。

"没有重点。"

易文没有回复。

他把手机放在桌上，屏幕朝上。十五分钟里屏幕亮了两次，一次是天气，一次是运营商短信。

隔了两个工位，蒋辉在打电话，声音不大但很清楚："对，纪总说两周后带数据组一起评估……不用，拦截器那块我来对接。"

这件事陈稳没听全后半句。他记事本最后一行多了一个待办：

"问易文，今晚能不能打个电话。"
