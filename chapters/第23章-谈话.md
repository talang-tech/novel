# 第二十三章 · 谈话

十月十二日，星期一，上午七点。

陈稳从工位上站起来，看了一眼监控大盘，结算成功率百分之九十九点九九，资源池使用率百分之三十四。他关掉电脑，走出工位区。

电梯里没有人，他按了一楼，电梯往下走，停了一下，门开了，没有人进来，门关上，继续往下。

他走出楼，天已经亮了，阳光照在路面上，很淡。他拿出手机，看到何晚的消息。

「粥煮好了。在锅里，你自己盛。」

他走回家，打开门，闻到粥的味道。他换鞋，走到厨房，看到锅里的粥，白米粥，没有放其他东西。他盛了一碗，坐在餐桌前，喝了一口，很烫。他放下碗，等着。

他喝完粥，洗了碗，走进卧室，躺在床上，闭上眼睛。

他睡到下午两点，醒过来，拿起手机，没有消息。他坐起来，揉了揉眼睛，打开手机，看到纪衡的消息，九点四十七分发的。

「下午四点，来我办公室一趟。」

陈稳看着屏幕，没有说话。他放下手机，站起来，走到洗手间，洗脸，刷牙，换了一件衬衫。他看了一眼镜子里的自己，眼睛是红的，没有肿。他转身走出洗手间，拿起手机，出门。

下午三点五十分，他到一号楼，工位区人不多，大部分人都在工位上，有人看到他，点了点头，没有说话。他走到工位，坐下来，打开电脑，打开监控大盘，结算成功率百分之九十九点九九，资源池使用率百分之三十二。

他关掉电脑，站起来，走到纪衡的办公室门口，门开着，纪衡坐在办公桌前，看着电脑屏幕。

陈稳站在门口，没有说话。

纪衡抬起头，看着他。

「进来。」纪衡说。

陈稳走进办公室，坐在纪衡对面的椅子上。

纪衡看着电脑屏幕，没有说话。陈稳坐在椅子上，没有说话。办公室里很安静，空调的声音，键盘的声音，外面有人说话，但听不清。

纪衡抬起头，看着陈稳。

「你昨晚处理了一个事故。」纪衡说。

「嗯。」

「复盘我看了。写得很清楚。做了什么，为什么这样做，效果怎么样。没有废话。」

陈稳没有说话。

「你那个消息服务，上线了，运行正常，没有受影响。」

陈稳没有说话。

「你那个对账模块重构方案，我看了。时间表也看了。按你的计划执行。」

陈稳点了点头。

纪衡看着陈稳，没有说话。

「我找你来，不是说这个。」纪衡说。

陈稳看着纪衡。

「你上周四做的方案评审，我后来跟技术 VP 聊了一下。他说，你讲得比以前好。但他问了一个问题，我没有答上来。」

陈稳看着纪衡。

「他问，这个方案做完之后，能推广到其他业务线吗。」

陈稳没有说话。

「你的方案里，只写了结算系统。没有写其他业务线。」

陈稳点了点头。

「我问你一个问题。你那个数据治理的方案，跟这个对账模块重构的方案，能合在一起吗。」

陈稳没有说话。

「你不需要马上回答。明天早上给我答案。」

陈稳点了点头。

「还有一个事。你那个数据治理的方案，张磊那边已经推广到营销技术部了。周其正那边也在问，能不能用。」

陈稳没有说话。

「你之前写方案的时候，只写了结算系统。但你现在要想一下，如果别人要用你的方案，你需要准备什么。你那个数据加载接口，是按时间范围、商户 ID、对账类型批量查询。如果其他业务线要用，这些接口够不够。」

陈稳没有说话。

「你回去看一下。明天早上一起给我答案。」

陈稳点了点头。

「你那个消息服务，跟蒋辉的智能重试补偿方案，还有资源冲突吗。」纪衡说。

陈稳想了想，说：「现在没有了。」

「为什么。」

「之前有冲突。消息服务跟规则引擎调度服务共用同一个资源池。昨天的事故之后，蒋辉说，消息服务不需要推后了。」

纪衡看着陈稳，没有说话。

「他说的？」纪衡说。

「嗯。」

纪衡点了点头，没有说话。

「你那个消息服务，接下来有什么计划。」

陈稳想了想，说：「继续观察。运行稳定以后，加消费者幂等逻辑，加 TTL 索引，加本地失败日志表。」

「谁写的。」

「易文标的注释。」

纪衡看着陈稳，没有说话。

「你最近跟易文走得很近。」纪衡说。

陈稳没有说话。

「我不是说你不能跟她走得很近。我是说，你想清楚了吗。」

陈稳没有说话。

「你不需要回答。明天早上给我答案。」

陈稳点了点头。

「就这些。」纪衡说。

陈稳站起来，走出办公室，走回工位，坐下来，打开电脑，打开记事本，写一行：十月十二日，下午四点。纪衡找我谈话。他问了四个问题。第一，对账模块重构能不能推广到其他业务线。第二，数据治理方案跟对账模块重构能不能合在一起。第三，推广需要准备什么。第四，我跟易文走得太近，想清楚了吗。

他看了一遍，保存，关掉。

他打开对账模块重构方案，看了一遍，没有改，关掉。他打开数据治理方案，看了一遍，没有改，关掉。

他站起来，走到茶水间，倒了一杯水，站在窗边，喝了一口，看着外面。阳光照在对面楼的玻璃上，反光，刺眼。

他想起蒋辉在茶水间说过的那句话：你最近跟易文走得很近啊。你跟易文走得太近，有人会看到。

他喝了一口水，没有想明白，把水喝完，把杯子放进水池里，走回工位，坐下来，打开记事本，写一行：十月十二日，下午。纪衡说，你最近跟易文走得很近。蒋辉也说过同样的话。

他看了一遍，保存，关掉。

他打开对账模块重构方案，开始看。他一行一行地看，一个字一个字地看。他看了四十分钟，看完了，没有改，关掉。

他打开数据治理方案，开始看。一行一行地看，看完了，没有改，关掉。

他打开记事本，写一行：十月十二日，下午五点半。两个方案都看了一遍。没有改。不知道怎么合在一起。

他看了一遍，保存，关掉。

他站起来，走到窗边，看着外面，站了一会儿，走回工位，坐下来，打开对账模块重构方案，开始改。

他把方案的第一部分改了。他把标题从「结算系统对账模块重构方案」改成「对账模块重构方案——事件驱动加增量比对，实现 T+0 实时对账」。他把原来只针对结算系统的描述，改成适用于所有业务线的通用描述。他改了半个小时，看了一遍，觉得不对，删掉，恢复到原来的版本。

他关掉方案，打开记事本，写一行：十月十二日，下午六点。改了一版，觉得不对，删了。

他看了一遍，保存，关掉。

他打开手机，看到易文的消息。

「听说纪衡找你谈话了。」

「嗯。」

「说了什么。」

「他问我，对账模块重构方案能不能推广到其他业务线。数据治理方案能不能跟对账模块重构合在一起。」

「你怎么回答的。」

「我说回去想一下。」

「你现在在想什么。」

陈稳看着屏幕，没有说话。

「我不知道怎么合在一起。」他打字。

「你先把两个方案打开，放在一起看。」

陈稳打开两个方案，左边是对账模块重构，右边是数据治理。

「然后呢。」

「看它们有什么共同点。」

陈稳看着两个方案，看了一遍，没有看到共同点。

「数据治理方案，你做了什么。」

「字段对齐。三个表，一百多个字段，统一成了四十二个字段。」

「对账模块重构方案，你做了什么。」

「事件驱动加增量比对，T+0 实时对账。」

「这两个方案，有一个共同的东西。」

陈稳看着屏幕，没有说话。

「数据。」

陈稳看着屏幕，没有说话。

「数据治理方案做的是底层数据对齐。对账模块重构方案做的是上层数据比对。底层对齐了，上层比对才能做。这两个方案，本来就是一个整体。」

陈稳看着屏幕，没有说话。

「你把数据治理方案改成对账模块重构方案的第一部分。第二部分才是事件驱动加增量比对的实时对账。这样，两个方案就合在一起了。」

陈稳看着屏幕，没有说话。

「你试一下。」

「好。」

陈稳放下手机，打开对账模块重构方案，分成两部分。第一部分：数据治理。他把数据治理方案的内容写进去，字段对齐、视图创建、数据清洗，三页，全部写进去。第二部分：事件驱动加增量比对。

他写完了，看了一遍，觉得可以，保存，关掉。

他打开手机，看到易文的消息。

「改完了吗。」

「改完了。」

「怎么改的。」

「第一部分写数据治理，第二部分写实时对账。」

「可以。」

陈稳看着屏幕，没有说话。

「还有一个问题。」他打字。

「纪衡问，如果推广到其他业务线，需要准备什么。」

「你那个数据加载接口，是按时间范围、商户 ID、对账类型批量查询。如果其他业务线要用，你做成可配置的。业务线自己配字段名、字段类型、数据源。你不需要改代码，改配置就行。」

「你能做吗。」

「能。」

「那就做。」

陈稳放下手机，打开方案，在第三部分加了一小节：可配置数据加载接口，支持按业务线配置字段名、字段类型、数据源。

他写完，看了一遍，觉得可以，保存，关掉。

他打开记事本，写一行：十月十二日，晚上七点。方案改完了。第一部分写数据治理，第二部分写实时对账，第三部分写可配置数据加载接口。

他看了一遍，保存，关掉。

他站起来，走到窗边，看着外面。天已经黑了，对面楼的灯亮着，几扇窗，零星的。他看了一会儿，没有走回工位。

他站在窗边，看着对面那扇窗，那扇他在看了一年多的窗，灯是黑的。

他站了一会儿，走回工位，坐下来，打开手机，看到何晚的消息。

「你今晚回来吃饭吗。」

陈稳看着屏幕，没有说话。

「我做了饭。」何晚说。

「你吃了吗。」

「还没。」

「我回来吃。」

陈稳放下手机，关掉电脑，站起来，走出工位区。

他走到楼下，天已经黑了，路灯亮着，路上没有人。他走回家，打开门，闻到炒菜的味道。他换鞋，走到厨房，看到何晚在炒菜，系着围裙，锅里的油在响。

「回来了。」何晚说，没有回头。

「嗯。」

「洗手，吃饭。」

陈稳走进洗手间，洗了手，走回餐厅，坐在椅子上。何晚把菜端上来，一盘青菜，一盘肉丝，一碗汤。她坐下来，看着陈稳。

「你昨天没睡好。」何晚说。

「嗯。值班，处理了一个事故。」

「严重吗。」

「不严重。已经恢复了。」

「你吃粥了吗。」

「吃了。」

「吃了就好。」

何晚拿起筷子，夹了一块肉，放在陈稳的碗里。陈稳看着碗里的肉，没有说话，夹起来，吃了。

「你胃不好，少吃肉。」

陈稳看着碗里的肉，没有说话，又夹起来，吃了。

「你今天下午去哪了。」何晚说。

「公司。纪衡找我谈话。」

「说什么了。」

「说了几个事。问我方案能不能推广到其他业务线。还问我，跟易文走得近，想清楚了吗。」

「你怎么回答的。」

「我说回去想一下。」

何晚看着陈稳，没有说话。

「你那个易文，她教了你很多。」何晚说。

陈稳没有说话。

「你以前不说谢谢。你以前觉得，什么事情都是应该的。你帮别人做事，别人帮你做事，都是应该的，不用说谢谢。你后来说谢谢了，是因为你开始在意别人怎么看了。」

陈稳看着何晚。

「你那个方案，能推广就推广，不能推广就算了。你不需要想太多。你那个纪衡，他问你跟易文走得近，想清楚了吗。你不需要想清楚。你跟她走得近，是因为她教了你东西。你学到了，就够了。」

何晚说完，拿起筷子，继续吃饭。

陈稳看着何晚，没有说话。他拿起筷子，夹了一块青菜，放在嘴里，嚼了，咽下去。

吃完饭，他洗了碗，走进卧室，坐在床边，拿起手机，看到易文的消息。

「明天早上，你给纪衡的答案，想好了吗。」

陈稳看着屏幕，没有说话。

「想好了。」他打字。

「你的答案是什么。」

「第一，对账模块重构可以推广到其他业务线。第二，数据治理方案跟对账模块重构可以合在一起。第三，可配置数据加载接口，支持按业务线配置字段名、字段类型、数据源。」

「第四呢。」

陈稳看着屏幕，没有说话。

「你不需要回答纪衡的第四个问题。他问你想清楚了吗，你不需要回答清楚还是不清楚。你只需要说，你学到了什么。他问，你再说。他不问，你不说。」

「好。」

陈稳放下手机，躺在床上，看着天花板。天花板是白的，没有裂缝。他看了一会儿，闭上眼睛。

十月十三日，星期二，上午九点。

陈稳到一号楼，工位区人已经齐了。他坐下来，打开电脑，打开监控大盘，结算成功率百分之九十九点九九，资源池使用率百分之三十一。他看了一会儿，关掉，站起来，走到纪衡的办公室门口，门开着，纪衡坐在办公桌前，看着电脑屏幕。

陈稳站在门口，没有说话。

纪衡抬起头，看着他。

「进来。」纪衡说。

陈稳走进办公室，坐在纪衡对面的椅子上。

「答案想好了吗。」纪衡说。

「想好了。」陈稳说。

「说。」

「第一，对账模块重构方案可以推广到其他业务线。第二，数据治理方案跟对账模块重构方案可以合在一起。第三，如果要做成平台方案，需要加可配置数据加载接口，支持按业务线配置字段名、字段类型、数据源。」

纪衡看着陈稳，没有说话。

「方案我改了一版。把数据治理方案的内容改成对账模块重构方案的第一部分，第二部分是事件驱动加增量比对的实时对账，第三部分是可配置数据加载接口。」

纪衡看着陈稳，没有说话。

「发我看一下。」

陈稳拿出手机，把方案发给纪衡。纪衡打开手机，看了一遍，放下手机，看着陈稳。

「你昨天改的。」

「嗯。」

「谁帮你改的。」

陈稳没有说话。

「易文？」纪衡说。

陈稳没有说话。

「你方案第三部分的可配置数据加载接口，是你自己想的，还是她帮你想的。」

陈稳想了想，说：「她帮我想的。」

纪衡看着陈稳，没有说话。

「你跟她学了很多。」

陈稳没有说话。

「你学到了什么。」

陈稳想了想，说：「我学会了，写方案的时候，要写别人能执行的。」

纪衡看着陈稳，没有说话。

「还有呢。」

陈稳想了想，说：「我学会了，说问题，不要说事实。」

纪衡看着陈稳，没有说话。

「你跟她学了很多。但你要知道，你学的东西，最后是你自己的。不是她的。」

陈稳没有说话。

「你那个方案，我看了。可以。按你的计划执行。先做结算系统，做完了，再跟张磊对接，看他那边需要什么。消息服务加幂等逻辑、TTL 索引、本地失败日志表。」

陈稳点了点头。

「就这些。」

陈稳站起来，走出办公室，走回工位，坐下来，打开电脑，打开记事本，写一行：十月十三日，上午九点。纪衡说方案可以。按计划执行。先做结算系统，做完再跟张磊对接。消息服务加幂等逻辑、TTL 索引、本地失败日志表。

他看了一遍，保存，关掉。

他打开方案，看了一遍，没有改，关掉。他打开消息服务代码，开始写消费者幂等逻辑。

他写到中午，在消息服务代码里加了一行注释。

```sql
-- 已消费消息表，去重，定时清理超过七天的记录
CREATE TABLE IF NOT EXISTS settle_message_consumed (
    message_id VARCHAR(64) PRIMARY KEY,
    consumed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_consumed_at (consumed_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

他写完，提交 MR，commit message：`feat: 消息服务加消费者幂等逻辑——已消费消息表去重，定时清理超过七天的记录`。

他打开记事本，写一行：十月十三日，中午。消息服务加消费者幂等逻辑。提交 MR。

他看了一遍，保存，关掉。

他站起来，走到茶水间，倒了一杯水，站在窗边，喝了一口，看着外面。阳光照在对面楼的玻璃上，反光，刺眼。

他想起纪衡说的那句话。

你跟她学了很多。但你要知道，你学的东西，最后是你自己的。不是她的。

他喝了一口水，没有想明白，把水喝完，把杯子放进水池里，走回工位，坐下来，打开代码，继续写。
