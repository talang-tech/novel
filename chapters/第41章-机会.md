# 第四十一章 · 机会

纪衡的消息是十二月二十三日九点零七分到的：「十点来我办公室。」

没有上下文，没有主题。陈稳回「好」。

他打开记事本看当天事项：推广方案对接确认 / 万征补充时间表 / 赵岩门禁记录。没有一条是纪衡。

九点五十。纪衡的办公室在三楼东边，靠窗。门开着。纪衡坐在办公桌后面，面前放着一台笔记本电脑和一个黑色笔记本。

「进来。关门。」

陈稳走进去，把门带上，在纪衡对面的椅子上坐下。椅子比纪衡的矮一点，坐下时座垫往下陷。他的视线平齐纪衡的电脑屏幕下沿。

纪衡把一封邮件看完，点了发送，合上盖子。

「新业务孵化组，你知道多少。」

「万钧那边。」

「对。万钧那边缺一个人。技术方案评审、对外技术沟通、合作方技术对接。他要一个能做技术方案的人——不只是能写，还要能讲给别人听。」

纪衡没有继续说。陈稳等着。

「我推荐了你。昨天双月会后，万钧给我打了一个电话。不是问你的方案。是问你要不要过来。」

「他怎么知道我。」

「他看过你的答辩。」纪衡的手指在桌沿上敲了一下。「你答那个技术影响力的问题，没答好。但他记住了你。」

「记住了我答得不好。」

「记住了你在答的时候在想。不是所有人被问到不会的问题时，会在那个位置上停下来想三秒再回答。大多数人会编一个答案。你没有编。」

陈稳看着桌面上一道细长的划痕，从笔记本下面延伸到键盘旁边。

「项目你做主。独立的服务资源，独立的技术选型，不需要共享资源池。结算组这边的推广方案，你还有两周，交完之后可以不跟了。」

「条件是什么。」

纪衡看了他一眼。不是审视，是确认。

「每周一次汇报，面向万钧和业务线的负责人。没有中间人，没有 PPT 模板，你自己讲。你讲清楚，项目继续。你讲不清楚，上面会把时间线和资源砍掉，或者换人。」

「你去了那边，讲的是技术方案，不是进度汇报。对方不一定是技术背景——可能是运营、是商务、是产品。他们问的问题不是'你怎么做的'，是'你做的这个东西对我们有什么用'。」

「我知道。」

「你知道。那你告诉我。你现在手上这个推广方案，它对万钧有什么用。」

陈稳把推广方案从万钧的角度过了一遍。万钧要的不是结算优化，是「这东西能不能帮新业务省成本」。

「十二个月的运营成本。推广方案覆盖六条业务线之后，全年资损预估降低大约一千万。新业务孵化组的业务如果接入同样的方案，结算环节的资损率可以从千分之一点七降到千分之零点三以下。按新业务明年的预估流水，大约可以省七百万。」

纪衡看了他几秒。「你什么时候算的这一笔。」

「你问完问题的时候。」

纪衡把笔记本翻到空白页，写了一个词。合上。

「万钧那边，一月第一周入职。你有两周时间把推广方案收尾。下周三之前给我答复。」

「我想一想。」

「你没听明白。我不是让你想。你已经知道你要去。我只是让你在答复之前，想清楚过去之后你要怎么活。」

陈稳没有接话。

「万钧不是坏人。但跟我不一样。他不看方案，不看过程，不看你的难处。他只看结果。你在结算组学的那一套——数据治理、价值量化、问题加方法——去了那边全部要重来。不是因为那些不对。是因为那边不认。」

「那边认什么。」

「认你能不能在一个陌生的会议室里，对着一群不认识你、不信任你的人，把一件事讲明白。你在我这里学会了对我说。你还没学会对他们说。」

陈稳走到门口。手放在门把手上。

「你刚才问我为什么推荐你。」纪衡的声音从背后传来。陈稳没有回头。「第一，结算组只有你一个人能写也能讲。虽然你讲得还不怎么样。第二，你在这边学会的东西，够你过去用，但不够你过去活。」

「第三是什么。」

「你刚才问了第一个问题就问了'条件是什么'。大多数人听完这个安排会先问'什么时候去'。你先问条件。这一点，你在结算组学不会。但万钧那边能教会你。」

走廊里没人。地面上有一条拖把拖过的水痕，已经干了，剩下一道隐约的白线。

陈稳坐回工位，打开记事本，在「推广方案对接确认」下面加了一行：**纪衡推我去万钧那边。一月第一周。** 他圈了起来。

中午他给何晚发了一条消息：「晚上晚一点回。下午有事。」

何晚回：「好。鱼热一下就能吃。」

十二点四十分。食堂的菜是红烧肉、炒豆芽、紫菜蛋花汤。他打了一份，找了个角落坐下。旁边桌有三个技术部的人在讨论一个线上问题。他没有往那边看。

他拿出手机打开通讯录。搜「万钧」。没有存过号码。他锁了屏。

---

下午一点四十。运维部五楼。走廊两侧是整排的服务器机柜，风扇的嗡声从门缝里挤出来。走廊尽头是监控室。

赵岩坐在里面，面前摊着三份打印件和一台笔记本电脑。

「坐。」赵岩把笔记本电脑转过来。「九月十七日二十一点四十三分，system.admin@ops 登录门禁管理系统，来源 IP 172.20.15.32。」

「这个 IP 是谁的。」

「办公区某个楼层交换机的内网地址。只能到楼层，不到具体工位。但往下查了一层。当时这个 IP 分配给二楼东区的 DHCP 池。二楼东区是营销技术部。」

「这个 IP 当时配给了哪个机器。」

「MAC 00:1E:06:A2:B3:C8，机器名 TPL-CN-172-027。」

赵岩把一张打印件推过来。上面用荧光笔标了一行：**资产编号：HLOPS-2024-0317 / 申领人：周其正 / 当前使用人：周其正。**

「周其正的电脑。」

「对。」

「九月十七日二十一点四十三分，周其正的电脑登录了 system.admin@ops，在门禁系统上执行了两条操作。第一条：创建临时授权——卡号 0189-0117（孙宇的卡），授权类型'一次性'，有效期二十四小时。第二条：清空授权人字段。」

「操作栏的默认字段是空白的。不是所有人都有这个权限。要让它空着，需要在数据库层面改设置。」

「谁能做到。」

「能登录这个账号的人都能做到。但知道这个漏洞的人不多。这个漏洞我八月份提过一个内部工单——」赵岩把第二张打印件推过来。工单编号 OPS-20260807-0043，标题「门禁系统授权人字段非必填缺陷」。提交人：**周其正**。

陈稳把纸拿起来。工单描述写了三步复现步骤、影响范围、修复建议。

「你什么时候知道的。」

「刚才。我今天拉日志之前也不知道是他。我本来以为是张毅。」

头顶的日光灯在嗡嗡响。墙上门禁状态图全绿。

「八月一日呢。」

「八月一日的系统管理员日志已经覆盖了。但我查了另一个东西。」赵岩打开第三个界面。「临时授权的创建如果走非正常流程——直接改数据库——不产生审批记录，但会产生一条 DDL 审计日志。」

「八月一日有一条。**2026-08-01 01:52:33**，操作类型 ALTER TABLE，目标表 auth_temp_auth，执行账号 sa_system——一个数据库层面的账号，不在门禁系统的用户体系里。」

「sa_system 是谁。」

「系统保留账号。不做日常管理。登录日志保留一年。理论上密码每季度轮换一次。实际上它已经被遗忘了。轮换列表里没有它。上次改密码是四年前。」

「所以你也不知道谁知道这个密码。」

「账号创建的时候密码归档方式跟现在不一样。四年前的归档方式是写在一张纸上，放进信封，封口贴了签字条，锁在运维部保险柜里。」

「现在谁有保险柜钥匙。」

「三个人：我、运维部负责人、还有——刘新。运维部副主管。他是四年前入职的。」

陈稳把三张打印件按顺序排好。周其正的电脑开了授权。周其正提交了漏洞工单。sa_system 改了数据库。刘新有保险柜钥匙。

「你为什么不直接告诉我是谁。」

「因为我不知道。有人用周其正的电脑开了授权——但不一定是周其正本人。有人提交了漏洞工单——但不代表他利用了这个漏洞。有人改了数据库——但不代表他是操作人本人。」

「你知道的。」

赵岩没有回答。

「你已经告诉我了。」陈稳把那三张纸折好，放进笔记本里。「你只是不想说出来。」

赵岩把笔记本电脑合上。「后天圣诞节。你今天拿到的这些，够你过个不安静的假期了。」

陈稳推开走廊尽头的门，外面的光涌进来，亮得刺眼。

---

下午三点四十。他把三张纸从笔记本里抽出来看了一遍。周其正。刘新。sa_system。八月一日。九月十七日。然后折好放进抽屉最里面，压在张磊汇金线台账的信封下面。

手机亮了。何晚的消息：「鱼还在。你几点回。」

「八点左右。」

「好。」

今天是十二月二十四日。他爸的生日。他打开微信，打了两个字：「爸，生日快乐。」发了出去。

他爸回了一个「好」字。没有标点，没有追问。就像陈稳发给他的每一条消息。

他知道自己不追问的习惯是从哪里来的了。

他打开 IDE，写万征的数据平台接口文档。光标停在屏幕上。他想起纪衡说的「你去那边，不是因为你准备好了。是因为结算组已经教不了你更多了」。

他删掉写到一半的注释。重新写。

他想起周其正——那个在数据治理项目会议室里手写过三页方案的人，钢笔字工工整整。推荐他用数据治理方案、叫他第一个接入对账模块、告诉他「可能查到最后是你不想知道的那个人」。

周其正知道。

他拿起手机打开通讯录。周其正的名字在屏幕上亮着。拇指悬在屏幕上方。

没有落下去。

他把手机放在桌上，不是锁屏，是没按。屏幕上「周其正」三个字还亮着。

他看了几秒。把手机翻了过去。

---

晚上八点。何晚在客厅沙发上改试卷。茶几上放着一盘鱼，用保鲜膜盖着。姜丝已经干在盘子边沿了。

「微波炉热一下。」何晚没抬头。

他端着盘子去了厨房。加热的时候，他看着转盘上的盘子慢慢转动。鱼眼睛在灯光下一圈一圈转过去。

热好了。他坐到餐桌旁。

何晚放下红笔，走过来坐到他旁边，给自己倒了一杯水，端着，没有喝。

「你今天去看了什么。」

「门禁日志。」

「然后呢。」

陈稳吃了一口鱼。

「周其正。九月十七日从他的电脑登录了门禁管理系统，给孙宇的卡做了临时授权。」

何晚拿着杯子的手停了大概四秒。「周其正。」

「对。」

「他跟这件事有什么关联。」

「不知道。他的电脑做了这件事。但不代表是他做的。」

「那你觉得呢。」

「我觉得不是他。但我没有证据。」

何晚把杯子放下，没有喝。「那你明天怎么对他。」

「不知道。」

「你不知道。」

陈稳的筷子停在碗沿上。他发现自己确实不知道。如果是以前，他会当这件事没发生过。但现在他知道太多，没办法假装不知道。

「你今天回来的时候一进门就在想这件事。」何晚说。「你换鞋的时候踢了一下鞋柜。」

「我没有。」

「你踢了。你没注意到。」

陈稳没有接话。他知道何晚不会记错。

「你以前不会踢东西。」何晚站起来，拿着杯子走向厨房。「你以前只会不说话。现在你是又踢东西又不说话。」

水流声从厨房传来。停了。

「明天圣诞节。我学校放假。你有安排吗。」

「没有。」

「那在家？」何晚从厨房走出来，把杯子放在餐桌上，杯底磕了一下桌面。「你把鱼吃完。别剩。」

陈稳吃完了那条鱼。姜丝和葱丝都吃完了。何晚把红笔笔帽扣上，站起来进了卧室。门没有关，留了一条缝。

陈稳把碗筷收到厨房，冲了一下。水流把姜丝和葱丝冲进滤网。他把滤网倒进垃圾桶。

他站在厨房窗前。对面的楼亮着许多扇窗。他找到了那扇。十一个月零二十七天。还是黑的。

他想起顾源说的：「技术是往前的，人是往回看的。」

他看着那扇黑着的窗。

---

十二月二十五日。圣诞节。早上七点多，窗帘外面的光是灰的，多云。何晚还在睡。桌上放着一杯温水和一张便签纸。何晚的字迹，圆珠笔写的：**「冰箱有鸡蛋。自己煮。中午我回来做饭。你别叫外卖。」**

他把便签纸对折了一下，放在桌上。

他打开笔记本电脑，把万征的数据平台接口文档写完。保存，发送。

十点零三分。万征回：**「接口文档收到。没问题。你那边还有什么需要的跟我说。」**

他回了一个「好」。

然后他点开周其正的对话框。上一次对话是十一月。再上面是他问 DHCP 分配记录，周其正回复了分配详情。再上面是空白的。

拇指悬在输入框上方。

打字。删掉。

再打。删掉。

**「周哥，有个事想问你。」**

他看着这几个字。没有发送。

不是因为害怕。是因为他还不知道想问什么。这些问题他没法问周其正——因为周其正会知道他在查什么。而他还没准备好让周其正知道。

他锁了屏。

中午十一点半。何晚回来了。她带了一袋菜。厨房里传来水流声、刀落在砧板上的声音、油锅的声音。这些声音陈稳小时候也听过。他妈用的不是不粘锅，是铁的。

「吃饭。」

今天的菜是三个：番茄炒蛋、青椒肉丝、紫菜汤。他想起自己第一次给何晚做菜的菜单——番茄炒蛋、青椒肉丝、紫菜汤。何晚那次说「你还会做菜？」。他说「简单的会」。

现在是同一个菜单。何晚做。他坐着吃。

「你今天没出门。」

「没有。」

「在想什么。」

「在想我怎么跟万钧说。」

何晚夹了一筷子番茄炒蛋，放到自己碗里。「万钧是谁。」

「新业务孵化组的负责人。纪衡要我去那边。」

何晚的筷子停了一下。「你要换组。」

「不算换。是借调。一月第一周过去。」

「跟现在的工作有什么区别。」

「更面向业务。要做技术方案的对外沟通。万钧不看过程，只看结果。」

何晚吃了一口饭，嚼了很久，咽下去。「你听起来像是已经决定了。」

「还没有。」

「你刚才说这句话的时候，眼睛在看窗外的那个方向。你没有看我。」

陈稳不知道自己刚才看的是哪里。但他确实没有看何晚。

「你以前做决定的时候不会告诉我。你只会做完之后说一声。你现在会在做之前跟我说了。这是进步。」

「所以你支持我去。」

「我没有说支持。我只是说你跟我说了。」

两个人继续吃。番茄炒蛋的盘子空了。青椒肉丝还剩一半。紫菜汤凉了。

吃完饭何晚去洗碗。陈稳坐在沙发上，听着水流的声音。

手机亮了。万钧的短信：**「纪衡跟我说了。一月第一周见。按给你的材料准备。第一次汇报我会在场。」**

他看了两遍。回「收到」。

他去了卧室，躺了半个下午。天花板上那道裂缝还在，比第一次看到时宽了一些。物业说「不影响结构」。

他想起这句话。不知道是相信了还是只是记住了。

晚上十一点左右何晚去睡了。他还在客厅坐着，关了灯。

手机亮了一下。赵岩的消息：**「下午我想了一件事。sa_system 账号四年前的密码归档信封，签字条上的签名是谁，我没记住。明天我去查一下。」**

陈稳看了两遍。

他回「别查了」。

然后删掉，重新打。**「如果查了，结果出来了，但你不能跟任何人说，包括我——你还查吗。」**

赵岩隔了大概四分钟才回。**「不查了。信封在那里。没人动过。那就让它在那里。」**

陈稳锁了屏。

客厅里只有窗外的光。楼下的路灯把影子拉得很长，伸到墙上。

他想起八月一日凌晨那个人。灰卫衣，金属表带的手表，从楼梯间来，从楼梯间走。他三秒输入了两条 DROP INDEX。他知道摄像头拍不到他的脸。他知道走廊的摄像头不会照到他的侧面。

这个人知道很多事。

他是周其正。他不是周其正。他认识周其正。他用了周其正的电脑。周其正知道他用过。

或者周其正不知道。

他在沙发上坐了很久。窗帘外面的光从灰变成深灰，从深灰变成黑。他没有开灯。

他想起顾源名单上最后一个人——张毅。在欢送会上说「查到最后只能查到一张卡」——周其正的电脑给孙宇的卡授权的。不是张毅的卡，是孙宇的卡。张毅站在走廊里说的那句话，像是一个早已知道答案的人讲出来的。

他用只有自己听得见的声音说了一句话。

「你还有一件事你不知道我知道。」

他把手机放在茶几上，屏幕朝下。

明天是十二月二十六日。下周一是他给纪衡答复的最后一天。

他不知道自己能不能带着这个没有答案的问题，去做一份需要他讲清楚所有事的工作。

他闭上眼睛。

十一月零二十八天。对面那扇窗还是黑的。
