# 第十七章 · 凌晨三点

九月十七日，星期四，上午九点。

陈稳到一号楼，坐下来，打开电脑，看到纪衡的邮件：压测数据已确认，方案通过。下周一进入大促备战执行阶段。

他看了一遍，没有回复。他打开监控大盘，看了一眼，结算成功率百分之九十九点九九，新服务器运行正常，连接池使用率百分之六十四。他关掉，打开 IDE，把压测脚本的代码又看了一遍，确认没有遗漏。

上午十点，他的值班手机响了。

不是告警，是排班提醒。陈稳看了一眼：九月十七日，星期四，值班二十四小时。他上次值班是八月二日，已经过去了一个半月。他拿起手机，签到，剩余时间二十三小时五十七分钟。

他把手机放回桌面，继续看代码。

下午两点，他去了三楼会议室，参加数据组和运维组的联合评审。纪衡不在，易文主持。会上讨论了压测数据，没有争议。运维组的人问了一个问题。

"双十一当天，如果新服务器扛不住，回退方案是什么。"

陈稳说当前架构已做了负载均衡，两台服务器互为备份，任何一台出问题可以自动切换。

运维组的人说好。

下午四点，会议结束。陈稳走回工位，坐下来，打开记事本，在「九月十七日 值班」后面打了一个勾。他看了一遍今天要做的事，确认没有遗漏，然后关掉，拿起手机，看到何晚的消息。

"明天晚上有没有空。"

他回：值班。明天早上才下班。

何晚没有回复。

他放下手机，继续看代码。他看的是结算对账模块的代码，之前他加了 TODO 注释：对账模块重构，当前实现基于逐笔比对，时间窗口为 T+1。目标：T+0 实时对账。他看了一遍，没有改，关掉。

晚上八点，他下楼，到食堂买了一碗面，端回来，坐在工位上吃。面是热的，汤是清的，没有味道。他全部吃完，把碗洗了，放在架子上。

他回到工位，坐下来，打开监控大盘，看了一眼，结算成功率百分之九十九点九九，连接池使用率百分之五十八。他关掉，打开 IDE，继续看代码。

晚上十点，他站起来，走到窗边，看着外面，星期四的晚上，停车场空了大半，路灯亮着，橘黄色的光照在地面上，没有人。他站了一会儿，走回来，坐下来，打开记事本，写了当天的工作日志，然后关掉，打开数据库，开始看数据。

他看的是结算对账表的索引使用情况。上次 settle_reconciliation 表的索引被人为删除，他查了 binlog，确认了 IP 但不知道是谁。他查了当前索引状态，一切正常。他关掉，打开配置变更检测脚本的输出，确认没有告警。

晚上十一点，他站起来，倒了一杯水，喝了一口，凉的，胃没有反应。他喝完，把杯子放在桌上，坐下来，打开 IDE，开始写代码。

他写的是结算对账模块的数据校验逻辑。他花了两个小时，写完了一百二十行，提交了一个 commit，commit message 写的是：`feat: 对账模块数据校验——校验字段类型、空值率、主键唯一性`。

他检查了一遍，确认没有问题，推上去，然后站起来，走到窗边，看着外面，深夜，停车场没有车，路灯亮着，橘黄色的光，安静。

他站了一会儿，走回来，坐下来，打开记事本，写了当天的第二行日志，然后关掉，打开监控大盘，看了一眼，结算成功率百分之九十九点九九，连接池使用率百分之五十二。他关掉，闭上眼睛，靠在椅背上。

他睡了一会儿。没有做梦。醒来的时候，值班手机屏幕亮着，显示时间：凌晨两点五十七分。

他拿起手机，看了一眼，没有告警。他放下，站起来，去洗手间，洗了一把脸，水是冷的，他擦干，走回来，坐下来，打开电脑。

凌晨三点零一分。

告警来了。

值班手机震了一下，屏幕亮起来，显示一条消息：结算系统——结算成功率下降至百分之九十九点一零，当前值百分之九十九点一零，阈值百分之九十九点九零，持续三分钟。

陈稳站起来，打开监控大盘，看了一眼。结算成功率曲线从百分之九十九点九九开始往下掉，掉了两分钟，停在百分之九十九点一零。连接池使用率从百分之五十二跳到了百分之八十三。CPU 从百分之十二跳到了百分之四十七。

他打开数据库，看了一眼连接数，一百五十个连接全部用满，大部分处于 sleep 状态，少数几个在执行查询。他看了一下执行中的查询，全部是对同一个表的全表扫描：`settle_transaction_log`。

这个表他记得。结算交易日志表，记录每一笔结算请求的完整链路。建表的时候没有做分区，没有做归档，数据量从二零二三年一月累积到现在，三年八个月，大约两亿行。全表扫描一次，在高峰期，能把连接池打满。

他没有查根因，先做了应急。他写了一条命令，把连接池上限从一百五十调到两百，执行，确认。然后写了一条命令，把 `settle_transaction_log` 的查询请求限流，只允许带时间范围条件的查询通过，不带时间范围的全部拒绝。执行，确认。

监控大盘上的数据开始回弹。连接池使用率从百分之八十三降到百分之六十一，CPU 从百分之四十七降到百分之十九，结算成功率从百分之九十九点一零升到百分之九十九点九零，然后回到百分之九十九点九九。

他看了五分钟，确认稳定了，然后打开数据库，查了根因。

两点四十八分，有一个定时任务跑了全表扫描，查询 `settle_transaction_log` 的全部数据，没有带时间范围，没有带索引条件。这个定时任务不是他写的，也不是蒋辉写的，是结算系统上线时写的一个数据归档脚本，从未被调用过，直到今天。

他查了 Git 历史。这个脚本创建于二零二三年一月，创建者是老梁。commit message 写的是：`feat: 结算交易日志归档脚本——按月归档，定时执行`。但归档逻辑从未被启用，因为归档的目标表没有建，定时任务没有配，脚本放在仓库里，三年八个月，没有人看过。

今天，有人手动执行了这个脚本。他在日志里查到了执行者的 IP：`10.14.1.88`。

陈稳看着那个 IP，没有说话。他查了 DHCP 分配记录，找到这个 IP 的分配记录：归属营销技术部测试环境 DHCP 池，最近一次分配时间是九月十七日二十一点三十分，分配给了营销技术部的一台测试机器。

他关掉日志，没有继续查。

他拿起手机，翻到易文的号码，看了一会儿，没有拨。他放下手机，打开数据库，开始分析 `settle_transaction_log` 的表结构。两亿行数据，没有分区，没有归档，索引不完整，查询计划显示全表扫描。他查了表的大小：约一百二十 GB。按当前增长速度，明年这个时候会到两百 GB。

他花了三十分钟，写了一个分区方案：按月份分区，保留最近十二个月的数据，旧数据自动归档到历史表。他把方案写完了，检查了一遍，没有发出去。他打开记事本，写了一行：分区方案已写完，周一发给纪衡。

他保存，关掉，打开 IDE，开始写代码。他写的是对 `settle_transaction_log` 的紧急修复：加一个索引，覆盖最常见的查询模式，禁止不带时间范围的全表扫描。他写完了，本地测试通过，提交了一个 commit，commit message 写的是：`fix: settle_transaction_log 全表扫描导致连接池打满——加索引，禁止不带时间范围的全表扫描`。

他推上去，然后打开数据库，执行了索引创建语句。执行时间十一秒，完成。

他确认了索引生效，然后打开记事本，写了一段话。

他写的是：今晚的事故，根因是三年八个月前的归档脚本从未启用。表没有分区，没有归档，两亿行全表扫描。应急方案：连接池上限从一百五十调到两百，禁止全表扫描。长期方案：按月分区，自动归档。

他看了一遍，保存，关掉。

凌晨四点零二分。

他坐在椅子上，没有动。手机震了一下，易文的消息。

"醒了。看到监控数据了。"

"嗯。"

"什么原因。"

"settle_transaction_log 全表扫描。一个归档脚本，老梁写的，三年八个月，今天第一次被调了。"

"谁调的。"

"同一个 IP。"

易文没有回复。

过了一会儿，她的消息又来了。

"你打算怎么办。"

"加了索引，限制了全表扫描。分区方案写完了，周一提交。"

"那个 IP 呢。"

"不查了。"

"为什么。"

"查了也没有用。IP 是测试环境的，谁都能用。"

易文没有回复。又过了一会儿，她说："你胆子真大。"

陈稳没有回复。

他放下手机，打开记事本，重新看了一遍他写的分段话。他想起易文说的那句话：先给结果，再给过程。他想起他删掉的那句话：这个改动能让每年两次以上的凌晨事故变成零次。

他打开一个新文档，开始写。

他写了两份复盘。第一份，技术版，写给自己的。标题：`settle_transaction_log 全表扫描事故复盘（内部）`。内容：根因、时间线、应急步骤、索引变更、分区方案。他写完了，一千二百字，保存为私有文档，不发送。

第二份，汇报版，写给纪衡的。标题：`九月十七日凌晨事故复盘——结算交易日志表归档缺失导致连接池打满`。内容：事故时间、影响范围、根因、应急措施、长期方案、预期效果。他写完了，四百字，加了一行预期效果：该修复可覆盖每年两次以上的凌晨事故，预期减少资损约三十万元。

他看了一遍，删掉了最后一句「预期减少资损约三十万元」。

他重新写了一句：预计将此类凌晨事故的发生概率降至零。

他看了一遍，保存，没有发。

他打开记事本，找到他之前写的那段话：他删掉的那句「这个改动能让每年两次以上的凌晨事故变成零次」，他重新写了一遍，写的是：这个改动能让每年两次以上的凌晨事故变成零次。

他看了一遍，没有删。

凌晨五点零三分。

他站起来，去洗手间，洗了一把脸，水是冷的，他擦干，看着镜子里的自己，眼睛里有血丝，脸上没有表情。他看了一会儿，走回来，坐下来，打开监控大盘，看了一眼，结算成功率百分之九十九点九九，连接池使用率百分之四十七。他关掉，打开 IDE，继续看代码。

他看的是那个归档脚本的代码。老梁写的，三年八个月前，一百一十行 Python，逻辑干净，注释清晰。他看完了一遍，没有改，关掉。

早上六点，天色开始亮了。他从窗户看出去，天空从黑色变成深蓝，然后变成灰白，云层很低，今天可能是阴天。他看了一会儿，走回来，坐下来，打开记事本，写了当天的第三行日志：凌晨三点零一分，事故告警，应急处理，四十分钟恢复。根因：三年八个月前的归档脚本从未启用，`settle_transaction_log` 全表扫描。已修复。

他看了一遍，保存，关掉。

早上七点，他下楼，到食堂买了一碗粥，一个鸡蛋，拿回来，坐在工位上吃。粥是热的，鸡蛋是凉的。他吃完，把碗洗了，把鸡蛋壳扔了，走回来，坐下来，打开电脑，把汇报版复盘发给了纪衡。

正文写了一行：九月十七日凌晨三点零一分，结算系统事故复盘——根因、应急措施、修复方案，详见附件。

他按了发送。

早上七点四十分，纪衡的回复：收到。方案可以。分区方案周一前提交。

他回了一个字：好。

他放下手机，打开数据库，开始写分区方案。他把之前写的方案重新整理了一遍，加了时间线、风险评估、回退预案。他写完了，两千字，检查了一遍，保存，没有发。纪衡说周一前提交，现在才周四。

他打开记事本，在「九月十七日 值班」后面又打了一个勾，然后写：分区方案已写完，下周一发。

他看了一遍，保存，关掉，打开 IDE，打开那个归档脚本，开始改。

他花了一个小时，把归档脚本改完了。他加了分区表创建逻辑，加了归档目标表创建逻辑，加了定时任务注册逻辑，加了异常处理，加了日志输出。他把老梁的一百一十行改成了三百行，测试通过，提交了一个 commit，commit message 写的是：`feat: 结算交易日志归档脚本重构——按月分区，自动归档，定时执行`。

他推上去，然后打开了记事本，在他写的那段话后面加了一行字。

他写的是：老梁的脚本，三年八个月，第一次被调用。不是被定时任务调用的，是被事故调用的。

他看了一遍，保存，关掉。

早上九点，值班手机震了一下，显示签到已完成，剩余时间归零，值班结束。

陈稳拿起手机，看了一会儿，放下。

他站起来，走到窗边，看着外面，星期四的早上，灰色的天，停车场里车开始多起来，有人从地铁站走出来，快步走进大楼，低头看手机，没有抬头看天。

他看了一会儿，走回来，坐下来，打开电脑，打开监控大盘，看了一眼，结算成功率百分之九十九点九九，连接池使用率百分之四十五。他关掉，打开 IDE，把归档脚本的代码又看了一遍，确认没有遗漏，然后关掉，拿起手机，看到易文的消息。

"分区方案写完了发我看看。"

"好。"

他打开电脑，把分区方案发给了易文。过了十分钟，易文的回复来了。

"方案可以。但有一个问题。"

"什么。"

"你那个归档脚本，跑在什么机器上。"

陈稳愣了一下。他写归档脚本的时候，没有考虑执行环境。老梁的脚本也没有，它只是放在仓库里。

"你写分区方案，写了执行环境吗。"

"没有。"

"补上。"

陈稳打开分区方案，加上了一行：归档脚本执行环境——二号楼数据库服务器，定时任务每天凌晨两点执行。

他改完，重新发给易文。

"可以了。"

陈稳放下手机，看着屏幕上的方案，没有动。他想起易文说的那句话：你写方案，要写别人能执行的。他想起他刚才写的归档脚本，没有写执行环境，没有写定时任务配置，没有写依赖。他写的代码，老梁的代码，都是写给自己看的。但三年八个月，没有人知道它怎么跑。

他打开记事本，写了一行字：写方案的时候，要写别人能执行的。

他看了一遍，保存，关掉。

他站起来，走到电梯口，按了一楼，电梯来了，他走进去，门关上。他站在电梯里，看着电梯门上的倒影，眼睛里有血丝，脸上没有表情。他想起三个小时前，他在凌晨三点写了两份复盘，一份技术版，一份汇报版。他想起他删掉的那句话，又重新写了一遍。他想起他打开老梁的代码，改完了，推上去。

电梯到一楼，门打开，他走出来，走到停车场，站了一会儿，拿出手机，看到何晚的消息。

"值班结束了？"

"嗯。"

"回去睡一觉。"

"好。"

他放下手机，走回地铁站，列车到站，他上车，坐下来，闭上眼睛，没有睡着。他想起老梁的代码，三年八个月，一百一十行，注释写得比代码还长。他想起他为了加分区表创建逻辑，把老梁的代码抄了一遍，然后把每一行都改了一遍。他想起老梁写这行代码的时候，二零二三年一月，还不知道自己会在三年后离职。

列车到站，他下车，走回小区，上楼，开门，换鞋，走进客厅，坐下来。

他坐了一会儿，站起来，走到窗边，看着外面，星期四的上午，灰色的天，对面那栋楼的窗户，一格一格地亮着，他看了十一个月的那扇窗，还是黑的。

他看了一会儿，走回客厅，坐下来，打开电脑，打开记事本，看到昨天写的三行日志，今天写的分区方案，凌晨写的两版复盘。他看了一遍，关掉，打开 IDE，打开那个归档脚本，又看了一遍，确认没有遗漏，然后关掉，站起来，走进卧室，躺下来，闭上眼睛。

他想起老梁的代码。他想起老梁写的那行注释：`# 按月归档，保留最近十二个月。` 他想起他三个月前在电梯里看到老梁抱着纸箱，纸箱上写着「梁栋」，笔画末尾拖了一下，收不住。

他闭上眼睛，过了一会儿，他睡着了。
