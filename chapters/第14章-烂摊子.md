# 第十四章 · 烂摊子

九月三日，星期四，上午九点。

陈稳到公司，打开电脑，打开邮件。纪衡没有新消息。蒋辉没有新消息。他打开记事本，看到昨天写的那一行：明天上午把方案发给纪衡。

他打开本地文件夹，找到昨晚写的那份三页接入方案，看了一遍，数据加载部分，拦截器接入部分，数据一致性保障部分，三页，每页都有他的名字。他看完了，没有发出去。

他关掉文档，打开监控大盘，绿的，平的，结算成功率百分之九十九点九九，拦截器正常，连接池使用率百分之六十五。他看了一会儿，关掉，站起来，去茶水间倒水。

茶水间里，咖啡机下面有一个人，弯着腰，在拆咖啡机的盖子。陈稳认出来，是易文。她穿着一件灰色短袖，袖子卷到肩膀，手里拧着一个螺丝，咖啡机盖子上卡着一块塑料板，她拧了两下，没拧动，换了一个方向，拧开了。

"你还会修咖啡机。"陈稳说。

"拧螺丝不需要会。"易文说，把盖子取下来，看了一眼里面的管道，把盖子又装回去了，拧上螺丝，拍了拍手，"好了。现在它还是没人调。"

她转身看到陈稳端着一个空杯子，说方案发给纪衡了没有。他说没有。易文问他为什么。他说，还没想好怎么说。

"你写都写完了，你跟我说还没想好怎么说。"

"……发出去就收不回来了。"

易文看了他一眼，没有接话，拿起自己的杯子，倒了一杯水，喝了一口，然后说："你跟我来。"

她端着杯子走出茶水间，没有回头。陈稳跟上去，走在她后面，穿过走廊，走到电梯口，按了下行键，电梯来了，她走进去，按了一楼，他跟着进去。电梯门关上。

"去哪里。"陈稳说。

"数据治理。你跟我一起。"

"什么数据治理。"

"到了你就知道了。"

电梯到一楼，门打开，易文走出去，穿过大堂，走到门口，推开门，外面是停车场，阳光照在地面上，水泥地面反射出一层白。易文走到一辆白色轿车前面，拉开副驾的门，回头看着他。

"上车。"

陈稳上了车，关上门。车内很干净，没有挂饰，没有摆件，储物格里放着一瓶水和一个充电器，中控台屏幕亮着，显示导航界面，目的地是恒澜科技园区二号楼，距离两公里。

易文发动车，开出去，没有开空调，摇下车窗，风灌进来，吹在脸上，热的风。陈稳坐在副驾上，没有说话，看着窗外，车从停车场拐出去，上了主路，经过两个路口，右转，进了恒澜科技园区二号楼的地下车库。

易文停好车，熄火，拉开车门，下了车。陈稳跟着下车，问她来二号楼做什么。她说二号楼的数据中心，做数据治理，前面有人等着。

"哪个项目。"陈稳说。

"没有项目。就是一个烂摊子。"

"什么烂摊子。"

"营销结算对账系统的底层数据，有三个表，结构不一致，数据对不上，营销技术部的人搞了两个月，没搞定，上周五找到我们部门，说让数据组帮忙看看。我看了，确实乱，但也不是不能做。"

"那为什么叫烂摊子。"

"因为没有人愿意接。所有人都说，这不是数据组的事，这是营销技术部自己没做好，不应该我们擦屁股。我组长说，这个月还有两个分析需求没做完，不做这个。我隔壁组的人说，这个数据太脏了，做出来也说不清楚。我上周五看完，跟组长说，我做。组长说，你自己想清楚，做这个不带任何绩效。我说，我知道。"

陈稳没有说话。

"你怎么不说话。"

"……说不接的人，都说对了。这不是你的事。"

"是。不是我的事。但这个东西在这里，没人做，它就在这里。两个月，三个月，半年，它会变脏，但不解决。直到有一天，有人做系统升级，发现数据对不上，查出来是底层的锅，然后就被记住了。但不是记住做的人，是记住出问题的人。"

陈稳没有说话。

"你听懂了没有。"

"……听懂了。不想做它的理由全是对的，但留着不解决，它迟早会变成你的问题。"

"差不多。但还有一个原因。"易文说，推开门，走进二号楼的大厅，走过闸机，刷了工牌，回头看着他，"我做这个，是因为不出现在任何人的 OKR 里，所以没人管我怎么做。我做完了，数据清楚了，以后谁做对账、谁做报表、谁做分析，底层数据都是干净的。他们不会记住我，但他们每次用到的数据，都是我做过的。"

陈稳没有说话。

他们走进电梯，上到三楼，穿过走廊，走到一扇关着的门前，门牌写着"数据治理项目组——临时"。易文推开门，里面是一个二十平米的会议室，中间摆了一张长桌，桌上放着一台显示器，一个键盘，一个鼠标，还有一个笔记本，翻开着，里面写满了数字和简写。窗户开着，窗帘拉了一半，阳光照在桌面上，照在显示器上，屏幕亮着，显示一个数据库查询界面，左边是表结构，右边是查询结果。

易文走到显示器前面，坐下来，把键盘拉到面前，敲了几下，屏幕上的查询结果变了，变成一张表，三列，第一列是表名，第二列是字段数，第三列是行数。她指着屏幕说："这三个表，分别是营销结算的订单表、支付表、退款表。建表时间分别是去年六月、去年八月、今年一月。建表的人不是同一个人，字段定义没有做过对齐。"

陈稳走到显示器前面，弯下腰，看着屏幕上的表结构。三个表，加起来一百多个字段，字段名不一致，类型不一致，空值策略不一致。订单表的主键是 order_id，varchar(64)，支付表的主键是 pay_id，int，退款表的主键是 refund_id，varchar(32)，三个表之间没有外键，关联关系靠业务字段拼接，order_id 在支付表里叫 biz_order_no，在退款表里叫 source_order_id。

"你怎么看。"易文说。

"……统一字段名，统一类型，建视图。"

"多快。"

"如果只是建视图，两天。如果要把数据洗干净，一星期。"

"行。你来做。我不会写 SQL。"

陈稳看着她，没有说话。

"我认真的。我只会看数据，不会洗数据。你写 SQL，我对结果。你写完，我验证。我们两个，一个礼拜，把这个烂摊子清了。"

"……我手上有蒋辉的项目。"

"你跟蒋辉那个项目，你是配合，不是牵头。你把数据接口层的方案发给纪衡，然后说，数据加载部分已经写好了，拦截器接入部分已经写好了，数据一致性方案有了，接下去只需要配合测试。蒋辉需要你的时候，你出来配合。不需要你的时候，你过来洗数据。"

陈稳没有说话。

"你听懂了没有。"

"……听懂了。配合跟牵头，两件事，可以并行。"

"对。你手上没有主线任务，你只有依赖项。你把依赖项做完了，你的时间就空了。空出来的时间，做这个。"

陈稳看着显示器上那三个表的结构，一百多个字段，字段名不一样，类型不一样，三张表，三个人的写法，没有一个人想过以后会有人把它们连起来。他想起老梁说的那句话：东西不会说话。东西是死的。只有人会说话。

"想什么。"易文说。

"没什么。"

"你脸上有东西。你在想'这个事不该我来做'。"

陈稳没有说话。

"你知不知道，你刚才在想什么的时候，你的表情是什么。你嘴抿了一下，然后你看着屏幕，没有说话。你每次想'这个事不该我来做'的时候，你都是这个表情。"

陈稳没有说话。

"你听我说完。这个事确实不该你来做的。但如果你不做，它也不会有人做。你等两个月，等到纪衡让你做，你到时候做，没有任何区别。唯一的区别是，你现在做，你就有这个东西。你等一下做，你就是被安排的。"

"……那不一样吗。"

"一样。但一个是你的，一个是别人的。你听懂了没有。"

他没有回答。他坐在显示器前面，打开数据库，开始看那三个表的数据。他看了四十分钟，把每个表的字段都过了一遍，把不一致的字段标出来，把空值率高的字段标出来，把重复的字段标出来。他在记事本上画了一张表，三列，每列一个表的字段名，然后用箭头把同义字段连起来。他画完了，看了一遍，箭头很乱，三条线交叉，四条线平行，还有两条线找不到对应。

易文坐在对面，翻着笔记本，没有看他。

中午十二点，他放下笔，站起来，说去吃饭。易文说楼下有食堂，三号食堂，比一楼的难吃，但人少。他说好，走出会议室，走到电梯口，按了下行键，电梯来了，他走进去，按了一楼。电梯门关上。

他站在电梯里，看着电梯门上的倒影，想起今天上午的事，想起易文说"你不是被安排的，你是在做你自己的事"，想起她说"你手上没有主线任务，你只有依赖项"，想起她说的那句话：你每次想'这个事不该我来做'的时候，你都是这个表情。

电梯到一楼，门打开，他走出来，走到食堂，打了一份饭，坐下来，开始吃。饭是热的，菜是普通的，红烧肉，青菜，米饭。他吃完了，把餐盘放到回收口，走出食堂，走到二号楼门口，站在门口，看着外面的停车场，阳光照在地面上，水泥地面反射出一层白。

他站了一会儿，没有回去，拿出手机，打开邮件，找到昨晚写的那份三页接入方案，看了一遍，然后按了发送。收件人：纪衡。抄送：蒋辉。标题：营销结算对账系统解耦——数据接口层接入方案。

他发完了，把手机放回口袋，走进二号楼，上楼，走进会议室，坐下来，打开数据库，继续看那三个表。

下午两点，他听到手机响了，是新邮件提醒。他打开，是纪衡的回复，一行字：方案收到。拦截器接入部分按你写的来。数据加载部分跟蒋辉确认接口。

他看完，没有回复，放下手机，继续看数据。

下午三点，他给蒋辉发了一条消息：数据接口层接入方案已经发给纪衡了，数据加载方法已拆分，接口定义在 MR 里，你确认一下接口格式，我配合改。

蒋辉回复：收到。我看一下。

下午四点，他收到蒋辉的回复：接口格式没问题，我这边先按这个走，有改动再同步。

他说好，放下手机，继续看数据。他已经把三个表的结构全部看完了，把同义字段标出来了，把不一致的字段定义写在了记事本上，写了一页，不够，翻了一页，继续写。他写完了，看着自己画的那张箭头图，三张表，十六个同义字段，五个字段名完全一致，七个字段名不一致但含义相同，四个字段名一致但类型或长度不同。

他在记事本上写了一行：建视图，统一字段名，字段类型以订单表为准，空值策略统一为 nullable。

他写完了，放下笔，告了一个段落，然后打开数据库，开始写 CREATE VIEW，一个字段一个字段地写，订单表的主键 order_id，支付表的 biz_order_no，退款的 source_order_id，他在视图里统一叫做 order_id，varchar(64)。他写完了第一个视图，十一个字段，二十二行 SQL，他检查了一遍，语法正确，提交执行。

他站起来，伸了一个懒腰，走到窗边，看着窗外，外面是停车场，车少了很多，阳光变软了，斜着照在墙上，下午四点多的太阳。他看了一会儿，走回来，坐下，继续写第二个视图。

下午六点，他写完了三个视图，六十八行 SQL，把三个表的一百多个字段压缩到了四十二个字段，统一了字段名、类型、空值策略。他检查了一遍，三个视图都创建成功，查询结果正确，数据行数对得上。

他打开记事本，在"建视图"后面打了一个勾，然后写：明天开始洗数据。他在下面又写了一行：先把字段空值率超过百分之三十的列标记出来，逐列确认是否可丢弃。

易文从对面的位置上站起来，问他写完了没有。他说三个视图写完了，明天开始洗数据。易文说行，明天早上九点，会议室见，然后背着包走了。

陈稳坐在会议室里，没有走。他打开数据库，又看了一遍那三个视图，检查了一遍字段名，确认没有问题，然后关掉，打开记事本，把今天做的事写了一遍：上午跟易文去二号楼，数据治理项目，三个表，一百多个字段，建了三个视图统一字段定义。他写完了，看了一遍，然后打开 IDE，打开蒋辉的 MR，看了一遍，接口格式确实没问题，他关掉，没有改东西。

他站起来，关掉显示器，走出会议室，走过走廊，走到电梯口，按了下行键，电梯来了，他走进去，按了一楼。电梯门关上。

他站在电梯里，看着电梯门上的倒影，想起今天早上他还在犹豫要不要把方案发出去，现在他已经发了，纪衡回复了，蒋辉确认了，他还写了三个视图，六十八行 SQL。他想起易文说的那句话：你现在做，你就有这个东西。

电梯到一楼，门打开，他走出二号楼，走到停车场，阳光已经没有了，天是灰蓝色的，风是凉的。他走到地铁站，刷卡，进站，等车，上车，站在车厢里，抓着扶手，看着窗外黑色的隧道。

列车到站，他下车，走回小区，上楼，开门，换鞋，走进客厅，坐下来，拿出手机，看到易文的消息，发在二十分钟前：视图发我看看。

他打开邮件，把三个视图的 SQL 文件发给了易文，正文一行：三个视图，字段统一了，你先看看数据对不对。

易文没有回复。

他放下手机，站起来，走进厨房，打开冰箱，拿出牛奶，倒了一杯，喝了一口，凉的，胃没有反应，他喝完，把杯子洗了，放在架子上。

他走回客厅，坐下来，拿起手机，看到易文的回复，不到五分钟：没问题。明天洗数据。

他回了一个字：好。

他放下手机，站起来，走到窗边，看着对面那栋楼，晚上，窗户亮着，一格一格的。他看了十一个月的那扇窗，还是黑的。他看了一会儿，走回客厅，坐下来，打开电脑，打开记事本，在明天的待办事项里写了一条：上午九点，二号楼，洗数据。下午，确认蒋辉的接口格式。

他写完了，关掉记事本，关掉电脑，站起来，走进卧室，躺在床上，看着天花板，没有裂缝，这间卧室没有裂缝。他看了一会儿，闭上眼睛。
