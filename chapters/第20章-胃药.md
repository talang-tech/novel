# 第二十章 · 胃药

九月二十七日，星期六，上午九点。

陈稳醒来，拿起手机，看到何晚的消息：「今天有事吗。」

「没有。」

「下午我去你公司附近。一起吃饭。」

「好。」

他放下手机，躺了一会儿，坐起来，走到客厅，倒了一杯水，喝完，站在窗边，看着外面，天空是灰的，没有太阳，没有雨。

他想起昨天的事。易文说，你学会了。他不确定自己学会了什么。他只知道，昨天他写方案的时候，一直在想，这句话是问题还是事实。他写一句，删一句，再写一句，再删一句。最后写出来的方案，跟他以前写的不一样了。但他不知道那样写对不对。

他打开手机，看到纪衡的消息：「方案改好了吗。」

「改好了。」

「周四讲。同样的时间，同样的会议室。技术 VP 也会来。」

「好。」

他放下手机，走进卫生间，洗漱，换衣服，穿上那件灰色衬衫，何晚买的皮鞋，四百八，鞋尖又起了一层皱。

他出门，坐地铁，到公司附近，找了一家面馆，坐下来，点了一碗面，吃完，付钱，走到公司楼下，坐在花坛边的长椅上，等何晚。

十一点半，何晚到了。她穿了一件白色短袖，牛仔裤，头发扎起来，手里拎着一个袋子。

「等了多久。」

「没多久。」

何晚把袋子递过来：「给你带了件衣服。你上次说那件衬衫袖口破了。」

陈稳接过来，没有打开：「谢谢。」

他们走到公司旁边一条街，找了一家小馆子，点了两个菜，一个汤。何晚帮陈稳倒了茶，给自己也倒了一杯。

「你上次说，你被纪衡叫去开了一个会，有一个叫顾源的人说了三句话，你答不上来。后来呢。」

「后来我回去改了方案。」

「改好了吗。」

「改好了。」

「那你周四还紧张吗。」

陈稳想了想：「不知道。」

「你以前不会说不知道。」

陈稳没有说话。

何晚没有追问。她夹了一筷子菜，吃了一口，放下筷子，看着窗外。过了一会儿，她站起来，去结账。陈稳站起来，拉住她：「我来。」

「你上次说你这月工资还没发。」

「发了。」

「多少。」

「够。」

何晚看着他，没有说话，松开手，让陈稳去结账。

陈稳结了账，四十二块。他走回来，何晚从包里拿出一个东西，放在桌上。

「胃药。你上次说那个吃完了。我去药店，问了一下，说这个比那个好。铝碳酸镁咀嚼片，你吃那个，吃多了对胃不好。这个是中成药，温和一点。」

陈稳看着桌上的药盒，没有说话。

「你拿着啊。」

陈稳拿起药盒，看了看，放进口袋里：「谢谢。」

「你不要光说谢谢。你要记得吃。你那天晚上回来，胃一直不舒服，你以为我不知道，但你翻了好几次身。」

陈稳没有说话。

「你那个公司，是不是有毒。」

「还行。」

「你每次都这么说。」

陈稳没有说话。

何晚站起来，走出馆子，站在门口。陈稳走出来，站在她身边。

「你下午有事吗。」

「没事。」

「那去你公司看看。」

陈稳愣了一下：「去我公司？」

「对。你从来没让我去看过。」

陈稳站了一会儿，没有说话，然后说：「好。」

他们走到公司楼下，陈稳刷卡，带何晚进去。电梯里只有他们两个人，何晚没有说话，陈稳也没有说话。电梯到了三楼，门打开，陈稳走出去，何晚跟在他后面。

工位区很安静，星期六，只有几个人在加班，坐在各自的工位上，没有人抬头。陈稳走过走廊，走到自己的工位，停下来。

何晚站在他身后，看着他的工位。桌上放着一台电脑，屏幕亮着，显示着监控大盘，绿色的数字，百分之九十九点九九，红色的曲线，平稳。旁边放着一个笔记本，翻到某一页，上面写着几行字，字迹潦草。再旁边，放着三个东西：一个水杯，一个充电器，一盒胃药。

何晚拿起那盒胃药，看了看，跟刚才她买的那个一样，铝碳酸镁咀嚼片，三十六粒装，已经打开，吃了三分之一。她放下，没有说话。

陈稳站在旁边，没有说话。

何晚又看了看桌上的笔记本，字迹潦草，但能看出来写的什么。「顾源三句话」「独立消息服务」「消息表迁移」「周四前改完」。她看完，合上笔记本，放回原位。

「你工位挺乱的。」

「嗯。」

「你以前不这样。你以前东西放得很整齐。你每次回家，都会把桌面收拾干净。你现在不收拾了。」

陈稳没有说话。

何晚没有追问。她走到窗边，看着外面，灰蒙蒙的天，没有太阳，没有雨。她看了一会儿，转过身，看着陈稳。

「走吧。」

「好。」

陈稳拿起桌上的胃药，放进口袋里，关掉电脑，转身，跟着何晚走出工位区。他们走到电梯口，等电梯。电梯来了，门打开，里面站着一个人。

蒋辉。

蒋辉看到陈稳，愣了一下，又看到何晚，笑了笑：「嫂子好。」

何晚点了点头：「你好。」

蒋辉走出电梯，陈稳和何晚走进去，电梯门关上。

何晚没有说话，陈稳也没有说话。电梯到了一楼，门打开，他们走出去，走出大楼，站在门口。

「那个人是谁。」

「蒋辉。」

「就是你说的那个，跟你做同一个项目的人。」

「嗯。」

「他今天也加班。」

「嗯。」

何晚没有再问。她站了一会儿，说：「我回去了。」

「我送你。」

「不用。你回去改方案吧。你不是说周四要讲吗。」

陈稳没有说话。

何晚看着他，过了一会儿，说：「你那个胃药，吃完了告诉我。我下次再给你买。」

「好。」

何晚转身，走了。陈稳站在门口，看着她的背影，看着她走远，转弯，不见了。

他站了一会儿，转身，走回大楼，刷卡，进电梯，回到三楼，走回工位，坐下来，打开电脑，屏幕亮了，监控大盘还在，绿色数字，百分之九十九点九九。

他打开记事本，在最后一行写：九月二十七日。何晚来公司了。她看到了我的工位。她说我变了。她给我买了胃药。

他看了一遍，保存，关掉。

他打开独立消息服务设计文档，看了起来。

---

九月二十八日，星期日，上午十点。

陈稳醒来，看到何晚的消息：「今天加班吗。」

「不。」

「那怎么安排。」

「在家改方案。」

「好。晚上过来吃饭。」

「好。」

他放下手机，坐起来，走到客厅，倒了一杯水，喝完，站在窗边，看着外面，太阳出来了，照在对面楼的玻璃上，反光，刺眼。

他打开电脑，打开独立消息服务设计文档，继续改。他改了消息表的结构，把主键从自增 ID 改为 UUID，避免跨数据库的自增冲突。把消息状态从三个枚举改为五个：待发送、已发送、已确认、已失败、已过期。把重试策略从固定间隔改为指数退避，初始间隔三十秒，最大间隔三十分钟，最多重试五次。

他改完了，看了一遍，保存，发给易文。

易文的回复在十分钟后：「消息表加了创建时间、发送时间、确认时间吗。」

「加了。」

「发给我看。」

陈稳把消息表结构发过去。

```
CREATE TABLE settle_message (
    message_id VARCHAR(64) PRIMARY KEY,
    message_type VARCHAR(32) NOT NULL,
    message_body TEXT NOT NULL,
    status VARCHAR(16) NOT NULL DEFAULT 'PENDING',
    retry_count INT NOT NULL DEFAULT 0,
    max_retries INT NOT NULL DEFAULT 5,
    next_retry_at DATETIME,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    sent_at DATETIME,
    confirmed_at DATETIME,
    expired_at DATETIME,
    INDEX idx_status_next_retry (status, next_retry_at),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

易文的回复：「可以。消费者幂等怎么做的。」

「消息 ID 去重。消费端维护一张已消费消息表，记录已消费的消息 ID，重复消息跳过。」

「已消费消息表有清理策略吗。」

「定时清理。超过七天的记录删除。」

「可以。」

陈稳放下手机，继续改方案。他写了消费者幂等逻辑，写了消息表清理策略，写了异常处理流程。他写了两个小时，把方案第三版改成了第四版，二千五百字，四部分：问题描述、方案设计、接口定义、异常处理。

他写完了，保存，关掉。

下午，他去了何晚家。何晚在厨房里做饭，陈稳站在门口，看着她的背影，没有进去。

「你站在门口干什么。」

「没什么。」

「进来坐。」

陈稳走进去，坐在沙发上，没有开电视，没有玩手机，坐着。

何晚从厨房里探出头：「你今天怎么这么安静。」

「在想事情。」

「想什么。」

「方案。周四要讲。上次没讲好，这次不能再讲不好。」

何晚没有说话，回到厨房里，继续做饭。

过了一会儿，她端出两碗面，放到桌上，坐下来，拿起筷子，吃了一口。陈稳也坐下来，拿起筷子，吃了一口。

「你觉得，你这次能讲好吗。」

「不知道。」

「你上次说，你写了十五分钟，纪衡说没有重点。这次你写了什么。」

「问题和方法。不是技术方案。」

「有什么区别。」

「上次我写的是，我做了什么，用了什么技术。这次我写的是，遇到了什么问题，用什么方法解决。」

「你觉得这样更好吗。」

「易文说这样更好。」

「那你觉得呢。」

陈稳想了想：「我觉得，这样写，别人更容易听懂。但我不确定，这样写是不是对的。」

「为什么不确定。」

「因为这样写，要少写很多技术细节。我不知道，少了那些细节，会不会漏掉什么东西。」

何晚没有说话，继续吃面。

陈稳也继续吃面。

吃完面，何晚收走碗，去洗碗。陈稳坐在桌前，没有动。他听着水声，想起今天下午写的方案，想起易文说的话，想起周四要讲的会。

他站起来，走到厨房门口，站在何晚身后。

何晚洗完碗，关掉水龙头，转过身，看到他站在身后，没有说话。她擦干手，走过他身边，走到客厅，坐下来，拿起手机。

陈稳走回客厅，坐下来，没有拿手机，靠在沙发上，看着天花板。

何晚过了一会儿，放下手机，看着他：「你今天晚上，还要回去改方案吗。」

「不改了。改完了。」

「那你看电视吗。」

「不看。」

「那你干什么。」

「坐着。」

何晚没有说话，站起来，走进卧室，过了一会儿，拿出一件叠好的衣服，放在陈稳身边：「你上次说那件衬衫袖口破了，我给你补好了。」

陈稳拿起衣服，看了看，袖口的破洞被缝好了，针脚很细，不仔细看，看不出来。

「谢谢。」

「你上次说谢谢，是谢谢你给你买胃药。这次说谢谢，是谢谢你给你补衣服。你什么时候能不跟我说谢谢。」

陈稳没有说话。

何晚看着他，没有说话，转身，走进卧室，关上门。门锁咔嗒一声响，不是锁上了，是关上了，没有锁。

陈稳坐了一会儿，站起来，走到窗边，看着外面，星期天的晚上，对面那栋楼，那扇黑着的窗，还是黑的。

他看了一会儿，走回客厅，把那件衬衫叠好，放进口袋里，穿上鞋，走到卧室门口，站了一会儿，说：「我走了。」

门内没有声音。

陈稳站了一会儿，转身，走到门口，开门，走出去，关上门。

他走下楼，走在小区里，路灯亮着，照在地上，他走得很慢。他想起何晚问他，你什么时候能不跟我说谢谢。他不知道怎么回答。他以前不会说谢谢，现在会说了，但何晚说，你什么时候能不跟我说谢谢。

他不知道自己什么时候学会说谢谢的。他以前不说谢谢。他以前不说很多话。现在他学会了说谢谢，学会了说问题而不是事实，学会了把方案写成问题加方法。但他不知道，这些变化是好还是不好。

他走到地铁站，上车，坐下来，拿出手机，看到易文的消息。

「方案第四版看完了。可以。周四用这个版本讲。有几个地方，我标了注释，你改一下。」

「好。」

他打开方案，看到易文标的注释，三处：消息表清理策略的七天时间窗口，建议改为根据业务量动态调整；消费者幂等逻辑的已消费消息表，建议加 TTL 索引；异常处理流程中，建议加一条：消息发送失败后，写入本地失败日志表，由定时任务扫描重试。

他看了一遍，全部改完，保存，发给易文。

「改完了。」

「可以。周四早上，再发一版给我看。」

「好。」

陈稳放下手机，靠在椅背上，看着地铁车厢里的灯光，白色的，亮得刺眼。他想起今天下午，何晚说，你什么时候能不跟我说谢谢。他想起他以前不会说谢谢。他想起他以前不会说很多话。

列车到站，他下车，走回小区，上楼，开门，换鞋，进门，坐下来，打开电脑，打开记事本，在最后一行写：九月二十八日。方案第四版改完。易文标了三处注释，全部改完。何晚说，你什么时候能不跟我说谢谢。我不知道。

他看了一遍，保存，关掉。

他走进卧室，躺下来，闭上眼睛。他想起今天下午，何晚站在厨房里做饭，他站在门口，看着她的背影。他想起她给他买的胃药，放在桌上，铝碳酸镁咀嚼片，三十六粒装，吃了三分之一。他想起她给他补好的衬衫，针脚很细，不仔细看，看不出来。

他翻了个身，没有睡着。

他起身，走到客厅，打开灯，打开电脑，打开方案，看了一遍。他没有改，只是看了一遍。然后又看了一遍。然后关掉，关灯，走回卧室，躺下来，闭上眼睛。

过了一会儿，他睡着了。

---

九月二十九日，星期一，上午九点。

陈稳到一号楼，看到纪衡的消息：「周四的方案，准备得怎么样了。」

「改完了。」

「发给我看。」

陈稳把方案第四版发给纪衡。

纪衡的回复在半小时后：「方案可以。周四上午十点，三楼会议室，讲十五分钟。技术 VP 也会来。你准备一下。」

「好。」

陈稳放下手机，打开监控大盘，结算成功率百分之九十九点九九，连接池使用率百分之四十三。他关掉，打开方案，看了一遍，关掉，打开独立消息服务设计文档，看了一遍，关掉。

他打开记事本，写一行：九月二十九日。纪衡说方案可以。周四上午十点，三楼会议室，讲十五分钟，技术 VP 会来。

他看了一遍，保存，关掉。

他站起来，走到窗边，看着外面，星期一，阳光很好，照在对面楼的玻璃上，反光，刺眼。

他站了一会儿，走回工位，坐下来，开始写方案第五版。
